# 美国住宅周期指标：长周期与近期分析

**结论：截至2026-10-10，美国住宅更像处在高新增融资成本下的成交和利润调整期，伴随局部库存消化，尚未形成一致的扩张信号。信用状况较金融危机时期稳健，不能等同于新买家购买力充足，也不能等同于建商利润已见底。**

## 如何定义“房地产周期”

五个周期可能不同步：

1. 融资周期：家庭能够取得贷款的利率、额度和条件。
2. 成交周期：购房申请、签约、新房销售及二手房过户。
3. 建设周期：许可、开工、在建及完工。
4. 价格与库存周期：库存清理、价格议价、折扣和地区供需。
5. 股东收益周期：建商利润率、现金回收、资本回报和证券估值。

政策利率下降，可能是衰退反应；低利率不保证银行放贷，也不保证失业家庭买房。新房销售回暖可能来自更大补贴；交付增长可能只是兑现早期订单。房价指数上涨可能滞后于签约改善。股价也可能提前反映预期，不能把股市上涨当成实体数据的独立确认。

以下的“领先、同步、滞后”主要是相对于建商未来交付和盈利；对GDP或房价，时序可能不同。不设所有周期通用的固定领先月数。

## 指标框架与判读方法

| 层次 | 指标、频率与来源 | 经济作用及常见时序 | 观察方法与容易误读的地方 |
|---|---|---|---|
| 融资 | 30年固定按揭利率，周，Freddie/FRED `MORTGAGE30US` | 直接影响新增月供，通常较快传导至申请与签约 | 看水平、最近变化和持续性；历史上7%不是普遍临界点，要结合房价、收入。 |
| 融资 | 10年国债收益率，日，`DGS10` | 长期限融资成本的重要基准 | 与按揭利率共同观察；Fed隔夜政策利率不是按揭利率的直接替代品。 |
| 融资 | 按揭利率减10年国债收益率，计算项 | 粗略观察长债以外的贷款定价变化 | 包含提前还款、期限、机构费用及利润等影响，不能称为纯MBS利差或直接解释为银行风险溢价。 |
| 融资 | Fed政策利率，月，`FEDFUNDS` | 影响金融条件，但可与长端利率分化 | 降息可能伴随就业恶化；要检查实际按揭是否下降。 |
| 购买力 | NAR固定利率可负担性指数，月，`FIXHAI` | 结合收入、房价、利率，比单看利率完整 | 100为中位收入家庭、20%首付等假设下的贷款资格边界；不是全部首次购房者都买得起。 |
| 购买力 | 典型新买家月供/收入、首付/收入，计算项 | 刻画边际买家的真正约束 | 本轮只作固定本金月供演示，未构造完整全国税费、保险及收入模型。房产税、保险、HOA及地区差异不能忽略。 |
| 需求 | MBA购房贷款申请，周，MBA | 比过户更早反映按揭购房需求 | 优先购买分项及4周均值；综合指数混入再融资，现金购房不在按揭申请中。未取得完整官方历史。 |
| 需求 | NAR待完成销售PHSI，月 | 签约通常领先成屋过户1—2个月 | 看持续改善与地区广度；100是2001年基准，不是经济学上的荣枯线。 |
| 需求 | 新房销量，月，Census/`HSN1F` | 按签约或定金计，较早反映新房需求 | 看3个月均值和同比；单月误差及修订大，成交可能靠优惠维持。 |
| 需求 | 成屋销量，月，NAR/`EXHOSLUSM495S` | 主要按完成过户计，滞后于签约 | 占美国住房交易的重要部分；低成交可能因锁定低利率和卖家不愿挂牌，未必只是需求弱。 |
| 信心 | NAHB HMI总指数，月 | 建商对市场的观察及预期，较快反映拐点 | 50是调查参考线，不是股价底部；水平与变化要分开。 |
| 信心 | NAHB购房者流量及未来6个月销售预期，月 | 流量更接近实际来访；预期更接近管理层判断 | 预期升、流量不升时须谨慎；来访增长仍不代表贷款资格或成交改善。 |
| 信心 | NAHB地区指数，月 | 刻画区域差异，减少全国均值掩盖 | 结合公司城市、价格带及客户结构；South和West不能代替每个城市的数据。 |
| 库存 | 新房库存月数，月，`MSACSR` | 同时反映存货及销售速度，关联促销与毛利率 | 分母是销售速度；月数下降可能只是销量回升，而非库存绝对量下降。不设置一条固定买入阈值。 |
| 库存 | 已完工未售新房，月，`NHFSEPC` | 建商已投入成本、可立即出售的库存，联系现金与促销压力 | 比总库存更接近成屋积压；本序列未季调，近期同比通常比连续月份更可比。 |
| 库存 | 未开工、在建、已完工库存分层，月，Census | 区分未来供给管线与已落地库存 | 本轮获取已完工分层和总库存发布；没有据总库存推算其余分项。 |
| 库存 | 成屋挂牌量、库存月数，月，NAR | 二手供给会与新房竞争，也可能释放换房交易 | 新房与成屋库存口径不同；挂牌上升不是无条件利空，也不是无条件利好。 |
| 定价 | 降价占比、销售激励、利率买断、有效售价 | 定价权变化，通常先于利润表完整体现 | 必须同时看基础售价和优惠；激励比例下降可能伴随底价下调。 |
| 建设 | 独栋住宅许可，月，`PERMIT1` | 开发商对后续活动的承诺，通常早于开工 | 本研究较重视该项；总许可受公寓项目影响，且许可并非必然开工。 |
| 建设 | 独栋开工，月，`HOUST1F` | 当前建设与未来交付供给 | 看3个月均值；天气、积压许可及项目节奏会造成月度波动。 |
| 建设 | 独栋完工及全部住宅完工，月，`COMPU1USA`、`COMPUTSA` | 滞后反映此前开工，新增竞争与库存供给 | 完工下降可能帮助去库存，也可能是过去需求弱的结果；不能当作即时需求反转。 |
| 价格 | Case-Shiller全国房价，月，`CSUSHPINSA` | 重复销售指标较好控制部分房屋组合变化 | 同比、区域及实际购买力要结合；统计有发布滞后，不是当天成交价格。 |
| 价格 | BIS实际住宅价格，季，`QUSR628BIS` | 去除一般通胀后的长期价格压力 | 不等于房价/收入或完整可负担性；不能把指数2010=100解释为估值中枢。 |
| 信用 | SLOOS住宅贷款标准与需求，季，Fed | 分清贷款供给收缩和借款需求不足 | 关注贷款类型；标准不变与处于历史宽松水平是不同概念。 |
| 信用 | 银行住宅按揭逾期率，季，`DRSFRMACBS` | 信用损失通常滞后，可帮助识别系统性危机 | 仅国内商业银行账内住宅按揭，不代表所有机构、所有住房贷款。 |
| 居民 | 房贷偿付/可支配收入，季，`MDSP`；总偿付负担`TDSP` | 反映存量债务现金压力 | 全国平均可因老业主低息贷款而保持低位，不能代替新增买家月供负担。 |
| 宏观 | 失业率、非农就业、实际人均可支配收入，月，`UNRATE`、`PAYEMS`、`A229RX0` | 决定购房能力、信心和信用质量 | 看就业增速与收入，不只看失业率水平；降息同时就业变差，净效果未必正面。 |
| 存量供需 | 自有住房空置率、租赁空置率，季，Census/FRED | 区分长期住房稀缺与短期交易库存 | 自有与租赁、全国与地方可分化；空置率低不保证可负担。 |
| 长期需求 | 家庭数量及形成速度，年，`TTLHH`；人口、年龄及迁移 | 比总人口更接近新增居住需求 | 年度调查可能修订；新家庭包括租房者，不等于同数量的新房买家。不能仅用人口增长估算住房缺口。 |
| 公司 | 净订单、取消率、每社区销量、积压订单 | 先于公司未来交付和营业收入 | 公司披露通常按季且区域不同；新社区数增长可能掩盖老社区需求下降。 |
| 公司 | 毛利率、营业利润率、滚动经营现金流、净债务、土地定金与资本周转 | 确认销量是否转化为股东收益 | 土地模式改变使利润率横比更复杂；回购、分拆和会计资本化也要分开处理。 |
| 证券 | 建商股价及相对大盘表现、估值 | 市场对未来的预期，可能领先实体 | 涨价既可能来自复苏预期，也可能是利率或情绪；本轮未据股价构建周期信号。 |

房租CPI和业主等价租金可以帮助观察通胀及货币政策，但反映存量租约、更新较慢，不宜作为新房需求的首要领先指标。工业、办公或公寓投资还需要新增租赁、空置、净吸纳、市场租金、NOI、资本化率、交易量和再融资条件；住宅贷款或NAHB信心不能直接替代它们。

## 长周期对照：不同低谷的原因不同

![长周期图](../../../data/derived/us-real-estate/housing-cycle/2026-10-10/housing-cycle-long.png)

以下数值从本次下载的历史序列计算；含事后修订，不是当时的实时数据版本。

| 周期阶段 | 已观察到的指标组合 | 对择时的启示 |
|---|---|---|
| 1970年代末—1982年 | 30年按揭在1981-10-09达18.63%；独栋开工在1981年10月约52.3万套折年 | 高通胀和高融资成本可以压低建设；当时住房价格、收入和人口结构不同，不能把当时的利率水平套到今天。 |
| 1989—1992年 | HMI在1991年1月降至20，1992年12月回升至56；建设受衰退及信用环境影响 | 低水平不是永久状态，但信心恢复需要与融资、贷款及真实成交配合。 |
| 2003—2006年上行与见顶 | 新房销量2005年7月约138.9万套折年；独栋许可2005年9月约179.8万套；独栋开工2006年1月约182.3万套 | 签约、许可和开工顶点不同；部分活动已经见顶时，后续交付或房价仍可较强。 |
| 2007—2012年崩塌与修复 | 许可2009年1月低至33.7万套；开工2009年3月35.3万套；HMI2009年1月8；新房销量2011年2月才低至27万套。新房库存月数2009年1月12.2；银行住宅按揭逾期率2010Q1约11.48% | 各指标有多个底；利率下降无法马上修复坏账、过剩供给及家庭资产负债表。不能用“降息开始”推导“复苏开始”。 |
| 2012—2019年渐进恢复 | 许可、开工及信心逐步回升；2018年HMI降至56后，2019年12月恢复至76 | 长期需求恢复中仍有利率扰动和阶段性调整；正常化可以持续多年，投资不必依赖下一季度拐点。 |
| 2020—2021年疫情重排 | 2020年4月HMI30，11月90；2021年1月按揭利率低至2.65%。供给受施工与供应链约束 | 需求与供给可能同时大变；疫情、补贴及迁移扰动使历史平均关系不稳定。 |
| 2022—2026年利率冲击与反复 | HMI2022年急跌；2023年反弹后又走弱。独栋许可从2021年1月约124.7万套降至2023年1月75.5万套，随后恢复，但2026年仍弱。新房库存月数保持偏高，银行按揭逾期率没有类似2008年的跃升 | 成交冻结、购买力约束和利润压缩，可以与较稳健的存量信用并存。当前更适合称为融资和可负担性调整，不宜直接类比次贷危机。 |

长期投资与短期择时要区分：看好十年住房需求，不等于预测下一年新房订单上涨；总量短缺也不保证每个阳光地带城市、每种价格段都短缺。

## 近期事实：截至2026-10-10可用观察值

| 指标 | 最新观察期与数值 | 变化及判断 |
|---|---|---|
| 30年按揭利率 | 2026-10-08，7.40% | 10月1日7.28%；2026年2月26日曾降至5.98%，之后改善被逆转。当前是近期的重要负面变化。 |
| 10年国债收益率 | 2026-10-08，5.22% | 同日按揭减国债约2.18个百分点。长端成本高，不能只关注Fed政策方向。 |
| 有效联邦基金利率 | 2026年9月月均3.75% | 与按揭水平显著不同；两者期限、定价与观察期不同，不能直接作同口径差额归因。 |
| NAHB总指数 | 2026年9月32，环比−3 | 未来销售37，−6；购房者流量23，持平。预期和真实流量都未形成共同上行。 |
| NAHB区域 | 2026年9月：东北35、中西部41、南部29、西部29 | South/West弱于中西部。LEN的重要地区暴露使全国均值不足以解释公司需求。 |
| 降价与销售激励 | 2026年9月38%建商降价，66%使用激励 | 分别高于8月35%、63%；平均降价约6%。定价权仍承压。 |
| 新房销量 | 2026年8月68.4万套折年，环比+6.4%、同比−2.0% | FRED三个月均值约66.63万，前3个月64.53万，约+3.3%，是正面线索；单月误差大，不足以确认复苏。 |
| 待完成成屋销售 | 2026年8月环比+0.3%、同比−4.7% | NAR新闻稿确认；签约微增而同比仍弱，尚未确认后续过户明显恢复。 |
| 成屋销量 | 2026年8月398万套折年，环比−2.0%、同比−1.2% | 新房与成屋没有同步强劲回暖；全年前8个月同比增长1.6%是需保留的正面证据。 |
| 新房总库存 | 2026年8月48.3万套、8.5个月 | 上月库存同为48.3万、9.0个月；月数下降主要伴随销售速度增加，并非总库存明显下降。 |
| 已完工未售新房 | 2026年8月11.2万套，未季调 | 同比约−8.9%，低于2025年12月13.4万套；近两个月持平。清理在发生，但应优先同比及季节背景，不能因几个月下行就认定需求强。 |
| 成屋库存 | 2026年8月162万套、4.9个月 | 7月157万、4.6个月；二手竞争增加，也可能释放更正常的换房链。 |
| 独栋许可 | Census 2026年8月87.8万套折年，环比−1.8% | FRED同月88.0万；FRED三月均值88.2万、前3月88.93万，约−0.8%。保留跨来源差异，不能把它们拼成同一精准序列。 |
| 独栋开工 | 2026年8月91.8万套折年，环比+7.6%、同比约+5.2% | FRED三月均值89.1万、前3月94.0万，约−5.2%；单月反弹尚未改变较弱的近期趋势。 |
| 独栋完工 | 2026年8月81.6万套折年，环比−10.4% | 后续供给增量可能放缓，但这是此前活动及施工节奏的结果，不是新订单复苏证据。 |
| Case-Shiller房价 | 2026年7月同比约+1.93% | 全国名义价格温和上涨；指数有发布滞后，不能代替10月或LEN地区的有效售价。 |
| 新房成交中位价 | Census 2026年8月39.37万美元，同比−5.8% | 定价可能承压，但中位价也受产品、区域和买家组合改变影响，不能当成同一套房下跌5.8%。 |
| NAR可负担性 | 2026年8月104.7，上年101.2 | 收入等因素带来改善；仍基于20%首付等假设，且不能代表利率升至7.4%后的10月状况。 |
| 住宅贷款标准和需求 | July 2026 SLOOS，主要对应Q2 | 多数住宅贷款标准基本不变、部分jumbo标准放松；各主要住宅类别需求转弱。不能概括为信贷全面收缩或已经回暖。 |
| 银行住宅按揭逾期率 | 2026Q2，1.86% | 上季1.88%；远低于2010Q1约11.48%。仅此银行账内样本，看不出次贷危机式跃升。 |
| 房贷偿付/收入 | 2026Q2，5.83% | 低于2007Q4约8.95%；存量平均较有韧性，不表示新增买家的负担轻。 |
| 自有住房/租赁空置率 | 2026Q2，1.2% / 7.3% | 自有空置低于2008Q1约2.9%，租赁并不呈现同等紧缺；不同市场的供需不可混同。 |
| 失业率与收入 | 失业率2026年9月4.2%；实际人均可支配收入8月同比约+1.1% | 就业收入提供支撑，但增速和后续变化需要持续观察，不能由当前低失业率保证未来订单。 |
| 家庭数量 | 2025年1.3479亿户，年频 | 这是长期需求背景，不能当成2026年8月购房需求即时测量；新增家庭包含租房者。 |

MBA官方页面本次访问受限，未取得可用于本轮长周期分析的购房申请历史。Gangtise命中资料中9月11日当周综合申请指数为230.8、环比−4.1%；9月27日材料的购买分项同比约+1.3%，再融资同比−34%。口径、观察期不同，这恰好说明综合申请不能代替购买需求；不把这两个片段拼成一条连续数据曲线。

## 三条需要互相制约的经济逻辑

### 1. 存量业主稳健，边际买家困难

固定利率贷款使老业主不必立即承担当前按揭利率。存量偿付负担和银行逾期率低，并不意味着首次购房者或换房者拥有相同融资条件。换房会失去原低利率，可能减少挂牌和成交；价格因供给不足保持坚挺，又进一步压制边际购买力。

计算演示：30年、10万美元本金、等额月供，仅本金和利息。3%利率月供约422美元；6%约600美元；7.4%约692美元。7.4%比3%的月供高约64.2%；在月供预算固定时，可贷本金约减少39.1%。这是同本金示例，不是全国平均月供，更未包含税、保险或首付。

### 2. 供给在收缩，未必已经开始需求扩张

完工减少、已完工库存同比下降，有助于未来利润修复；但这种调整可能只是通过少建房消化库存。若签约、流量、购买申请和许可仍不改善，应称为供给调整，不能提前称为新一轮增长。

近期新房销量三月均值改善是真实的正面证据；不过许可未同步上行、开工三月均值仍下降，预期与流量走弱，说明改善尚不广泛。新房库存月数下降而总库存持平，也提醒我们不要把分母变化全部解释为库存清理。

### 3. 量的底部可以早于利润的底部

建商可以依靠促销、降价和买断利率维持销量。对于LEN，土地银行期权维持费还可能在交付延期时增加，所以行业销量稳定并不自动改善现金流或毛利率。要看公司有效售价、单套成本、资本周转和滚动现金回收，不能只看交付套数。

同时，资本效率改善可能在行业不强时带来公司收益；这一点使伯克希尔买入LEN不能单凭宏观数据解释。[关联讨论](伯克希尔增持莱纳：个股机会还是周期反转.md)

## 接近底部需要什么状态，如何确认反转

**接近底部意味着供需失衡开始收敛；确认需求反转，需要购买力改善转化为持续的买家入场和签约；确认建商盈利反转，还需要成交质量与现金回收改善。**

以下主要针对当前融资成本与边际购买力约束较强的住宅市场；金融危机、供给严重短缺等阶段，需要调整指标权重。

![住宅周期底部：六组信号如何接力——需求接力情景示意](../../../data/derived/us-real-estate/housing-cycle/2026-10-10/housing-cycle-bottom-signals.png)

图示为“需求接力”假设情景，不是实际数据或预测。灰色区表示失衡收敛、形成底部候选；蓝色区表示随后需验证买家与订单恢复、成交对进一步让利的依赖减弱。各阶段时长不等，各图纵轴仅表达方向，不能比较量级。多项改善持续出现可增强底部判断，但不能保证反转在即；仅供给收缩或库存下降仍可能对应长期横盘，家庭与信用恶化也可能推翻早期判断。

### 1. 先区分成交、利润与股价的底部

成交底部关注签约和销售是否停止恶化、开始持续恢复；建商利润底部关注有效售价、成本、毛利率和现金回收；股票底部则包含对未来的预期与估值变化。股价可能先于实体数据上涨，利润也可能在成交恢复后继续下降，三者不存在每轮周期都固定适用的时序。

“已经接近底部”是一个有待验证的前瞻判断，不等于“下一季度一定反转”。供需可以在低成交水平重新取得平衡，形成较长的平台期。价格也未必同步见底：降价可以改善购买力，促使成交先恢复，而旧项目成本和折扣仍压制利润。

### 2. 底部或反转前夜应出现的状态

| 观察维度 | 接近底部的候选状态 | 经济机制与限制 |
|---|---|---|
| 边际购买力 | 新买家的月供/收入、首付负担停止恶化，开始改善 | 按揭下降、有效房价调整或收入增长，使部分买家重新具备购买能力。需包含税、保险和地区差异，不能只看Fed降息。 |
| 潜在需求 | 购房申请、买家流量停止持续下降，出现改善线索 | 买家重新进入决策过程；来访改善仍需贷款资格和签约确认。 |
| 供给管线 | 许可、开工此前已调整，未来新增未售完工压力趋缓 | 少建房可以缓解过剩，却不会自动创造需求；在住房供给短缺地区，建设收缩也可能限制成交恢复。 |
| 库存压力 | 已完工未售库存及账龄不再持续恶化，开始清理 | 最占用建商现金的库存得到控制；本轮未取得完整账龄数据，库存未季调，须结合同比和季节背景。 |
| 销售让利 | 优惠仍大，但继续扩大让利的必要性减弱 | 市场开始接近可成交的价格和月供水平。需看优惠金额和基础售价，而不只是“使用激励的建商比例”。 |
| 家庭与信用 | 就业、收入及贷款可得性没有恶化到抵消购买力改善 | 利率下降若伴随失业急升或信贷收缩，需求可能继续下降。低存量逾期率不能证明新增买家能借到钱。 |

对当前市场，较有解释力的组合是：**供给压力下降、边际购买力改善，同时家庭收入与信用没有同步崩坏。** 并不要求每一项同时出现，也不要求所有指标达到某个固定绝对水平；但只有供给收缩、没有买家与签约改善时，最多支持“供需再平衡”，尚不能确认需求扩张。

### 3. 哪些事件和变化能够确认反转

确认依据应是一条逐步兑现的经济链条，而不是某个政策新闻或一个月的数据跳升。融资改善、签约恢复、库存清理与盈利改善可能交错发生，下面的顺序用于理解传导，不代表固定领先月数。

| 验证环节 | 需要看到的事件或持续变化 | 能够支持的判断及反证 |
|---|---|---|
| 购买力改善传导到需求 | 实际按揭或建商提供的有效融资成本下降，购房申请和买家流量随之改善；或房价、收入变化产生同类效果 | 支持边际买家重新入场。若利率下降而购买申请继续下降，要检查就业、信用与观望因素。 |
| 签约持续恢复 | 新房销量、成屋待完成销售、建商净订单中多个指标持续改善，取消率下降 | 支持成交周期转向。公司订单应结合每社区销量，防止社区扩张掩盖既有项目需求下降。新房与成屋受不同供给约束，不要求完全同步。 |
| 库存改善具有质量 | 已完工库存与账龄改善，库存月数下降，同时销售稳定或增加 | 支持供需匹配改善。要拆开库存数量与销售速度；不能把总销量与总完工量相减来解释已完工库存，因为房屋可在完工前售出。 |
| 成交对进一步让利的依赖减弱 | 综合基础售价调整和销售优惠后，让利不再扩大，而净订单及每社区销量仍增长 | 较强支持需求与定价能力恢复。需控制地区、面积、产品档次和客户组合，排除小户型占比提高等造成的表观变化。 |
| 经营收益开始兑现 | 毛利率降幅收窄，滚动现金回收改善，随后利润率企稳 | 支持建商盈利周期反转。现金流还要拆解少买土地、释放营运资本等来源，不能把缩减投资形成的现金流改善全部归因于经营复苏。 |
| 改善具有广度 | 多个地区、价格带及多家建商出现类似改善，随后许可、开工与需求相适应 | 增强行业反转判断。单一公司可能因产品、成本或资本效率改善而增长；全国均值也可能掩盖主要城市继续恶化。 |

**最值得关注的经营确认信号是：建商无需提供更大的综合让利，仍能持续卖出更多房屋。** 这比单看销量增长更接近需求和定价权的共同改善。不过，成交反转可以早于利润反转，不能要求利润率先回升才承认需求恢复。

实际观察可使用约3—6个月的需求和签约数据，再以随后约两个季度的公司经营披露交叉验证；同时查看3个月均值、同比、数据修订和地区广度。这是降低单月噪声影响的研究方法，不是统计验证过的固定确认门槛，也不是必须等待的交易期限。

一次Fed降息、按揭跌破6%或7%、HMI越过50、新房销量单月大增、库存月数跌破某个整数，以及建商股价上涨，都不能单独确认反转。融资成本下降也不是所有复苏的必要条件：收入增长和有效房价调整同样可以改善购买力。

### 4. 区分去库存、需求恢复与盈利反转

| 观察到的组合 | 优先考虑的解释 | 还需验证什么 |
|---|---|---|
| 销量增加，优惠扩大，毛利率下降，买家流量偏弱 | 让利去库存，或签约节奏恢复 | 成交是否能在优惠稳定后延续；有效售价与取消率如何变化。 |
| 库存下降，销售停滞，新增供给明显收缩 | 主要由供给调整推动的再平衡 | 买家流量与签约是否随后恢复；新增未售完工量是否确实下降。 |
| 买家流量、净订单改善，取消率下降，综合让利不再扩大 | 需求恢复的证据增强 | 是否跨地区、跨公司延续，且不主要由社区扩张或产品组合变化推动。 |
| 需求改善延续，利润率和经营现金回收随后企稳 | 行业复苏开始兑现为经营收益 | 改善是否包含可持续的单套经济性与资本回报，而非仅缩减投资或一次性项目。 |

这些组合用于比较解释的相对说服力，不是互斥分类。供给调整、利率改善与促销可以同时发生；没有施工阶段、有效优惠和库存账龄等数据时，无法精确分解各因素贡献。

### 5. 当前市场距离确认还缺少什么

**来源事实：** 下表沿用本文“近期事实”部分截至2026-10-10已采集的数据，原始来源与本地保存位置见文末；未新增完整MBA购房申请、城市库存账龄或全国有效优惠序列。

| 当前证据 | 对框架的支持或制约 | 下一步需要补充的确认 |
|---|---|---|
| 2026年8月已完工未售库存11.2万套，同比约−8.9%，但7—8月持平 | 支持库存压力较此前缓解，近期下降并非持续 | 结合季节背景观察库存与账龄，判断是否继续改善，并核查新增未售完工量。 |
| 新房销量近3个月均值较前3个月约+3.3% | 支持成交出现修复线索 | 购买申请、买家流量、净订单与取消率能否共同改善。 |
| 10月8日按揭利率7.40%；9月HMI32、买家流量23 | 购买力和需求尚未形成共同改善 | 实际月供负担下降，且申请、来访与签约产生持续响应。 |
| 9月38%建商降价、66%使用激励，均高于8月 | 成交对让利的依赖仍是重要制约 | 在综合优惠稳定或减少时，成交能否继续增长。 |
| 独栋许可近3个月均值约−0.8%，开工约−5.2% | 尚无一致的建设扩张信号；库存压力缓解也可能来自缩减建设 | 先验证真实需求，再观察许可、开工是否作出与需求相适应的反应。 |

**分析结论：当前可以支持“库存调整正在推进、成交存在局部修复”，但尚不足以确认广泛需求反转，更不能确认建商盈利已见底。** “反转前夜”仍是待验证的假设；若购买力、买家流量和签约没有共同改善，库存清理也可能只带来低成交水平上的稳定。

对伯克希尔的动机，应保留两种解释：一是预期行业需求将较快恢复；二是认为即使行业恢复较慢，LEN的价格、资本效率和经营能力也能提供长期回报。要增强第一种解释，需要上述变化在多个地区和多家建商中发生。若仅LEN自身改善，仍可能主要是个股机会；即使行业后来反转，也不能倒推出伯克希尔当时已明确预测其时间点。

### 6. 后续情景与可能推翻当前判断的证据

| 可能路径 | 应观察到的组合 | 对建商投资的含义 |
|---|---|---|
| 购买力改善推动复苏 | 按揭、有效房价或收入带来购买力改善；购买申请、流量、签约恢复；许可随后作出响应；综合让利不再扩大而成交保持 | 较强支持住房需求周期反转。不能只用一次降息或一周利率下降确认。 |
| 供给清理与温和正常化 | 按揭仍高；已完工库存和新供给下降；销量企稳、费用受控；毛利及现金回收改善 | 可支持长期投资和部分公司重估，但不必意味着成交快速扩张。 |
| 需求再次恶化 | 就业收入变差；取消率上升；流量、签约转弱；库存及激励增加；信用恶化 | 便宜P/B和低存量逾期率不足以保证安全边际。 |

## 分歧与数据限制

- 当前研究主要是全国及四大地区数据；LEN、DHI还需要城市和价格带分析，尤其Texas、Florida及西部主要市场。
- 历史序列含事后修订。下载截止日和观察期已标注，但没有构建ALFRED逐期实时版本，不能作为无前视偏差的交易回测。
- NAR的成交、库存和可负担性在FRED受来源协议限制，部分仅有约13个月。没有虚构长历史或用其他指标冒充。
- Census初步2026年8月许可与FRED值不同：总许可139.4万 vs 140.3万，独栋87.8万 vs 88.0万；未确认具体修订原因。主表标注原始发布、图表沿用FRED整条序列，方向判断不依赖这项小差异。
- NAR待完成销售概览页面有重复且冲突的同比表述；本研究采用其完整官方新闻稿确认的−4.7%。
- 2026Q2的FRED日期记为2026-04-01，这是季度起始标签，不是只测量4月1日；2026年8月月度数据也不等于当日观察值。
- 已完工未售库存及部分NAR序列未季调；流量类数据多数是季调年率，不是真实当月成交或施工套数。
- 贷款逾期、偿付比与空置率的分母不同，不能合成一个居民风险比率。
- 本轮没有完整全国有效折扣价格、新增月供/收入、MBA购房申请或城市库存长序列。对这些指标仅给出判读框架和已取得片段。
