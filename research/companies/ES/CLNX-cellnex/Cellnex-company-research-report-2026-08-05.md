## 一、公司基本情况、历史沿革与经营部门

本章以《Integrated Annual Report 2025》前部的公司介绍和业务章节为主，尽量保留年报的披露口径。年报把 Cellnex 定义为欧洲无线通信基础设施运营商，并围绕“规模与覆盖、四条业务线、长期客户关系、资本配置和工业化运营”介绍公司。以下数据均标注为年报口径，不与官网其他页面的历史统计直接混用。[S24]

### 本章专有名词速查

第一章会同时使用通信工程、塔站运营和财务分析术语。下表先给出本文采用的含义；其中 `BTS`、`RAN`、`PoP` 等缩写在不同资料中可能有不同用法，阅读 Cellnex 年报时应以本表的上下文为准。[S24]

| 术语 | 中文理解 | 在 Cellnex 业务中的含义 |
|---|---|---|
| **TowerCo** | 塔站公司 | 持有或控制塔桅、屋顶、土地、机房等通信站址，向多个运营商出租共享使用权；Cellnex 的核心商业形态。 |
| **Telecom site / 站点** | 通信站址 | 一个可部署通信设备的位置及其配套设施，不一定等于“一座塔”，也可能是屋顶、杆路或特殊位置。 |
| **Towers** | 塔站业务 | Cellnex 的核心报告业务线，包含宏站、屋顶站、共址、BTS 建设、站点改造和运维。 |
| **Basic TowerCo / Adjacent Assets / Active Infrastructure** | 基础塔站/相邻资产/主动基础设施 | 年报的三层资产框架：基础塔站是塔桅和共址；相邻资产是 DAS、光纤、数据中心、广播等；主动基础设施是 RANaaS 和部分关键通信网络。 |
| **PoP（Point of Presence）** | 网络存在点/客户设备租用点 | 通常指一个客户在 Cellnex 站点上实际部署的一组设备或一项可计费占用；同一站点可以有多个 PoP。 |
| **Co-location** | 共址 | 多家运营商把各自的天线、射频、基带等主动设备放在同一个 Cellnex 站点上。 |
| **BTS（Build-to-Suit）** | 按客户需求新建站点 | Cellnex 根据客户覆盖计划负责选址、许可、建设、供电和交付。注意：通信技术文档中的 BTS 也可能指“基站设备”，本报告在项目数量处主要指 Build-to-Suit。 |
| **Build-to-Fit / site adaptation** | 既有站点改造 | 对现有塔站进行加固、换天线、扩容、增加供电或调整设备布局，使其适应新客户或 5G 网络。 |
| **DAS（Distributed Antenna System）** | 分布式天线系统 | 在建筑、机场、体育场、隧道等室内或地下场所布置多组天线，为多个运营商提供共同覆盖。 |
| **Small Cells** | 小基站/小蜂窝 | 功率较低、覆盖范围较小的无线节点，用来补充宏站在城市、室内和高人流区域的容量。 |
| **RAN（Radio Access Network）** | 无线接入网 | 手机与运营商核心网之间的无线部分，包括天线、无线单元和基带等设备。 |
| **RANaaS（RAN-as-a-Service）** | 无线接入网即服务 | Cellnex 在部分市场不仅提供塔站，还代客户提供主动无线设备和传输服务；波兰是年报重点案例。 |
| **O&M（Operations & Maintenance）** | 运营与维护 | 对站点、网络、设备和能源进行日常运行、监控、维修和故障处理；Cellnex 在部分国家提供，也可能退出非核心 O&M 合同。 |
| **Mission Critical / PPDR / TETRA** | 关键通信/公共安全通信 | 面向警察、消防、急救、政府和交通等场景的高可靠专用通信；TETRA 是其中一种专业数字集群通信标准。 |
| **FTTT（Fiber to the Tower）** | 光纤到塔 | 用光纤把塔站连接到运营商或其他网络节点，为 4G/5G 提供高容量回传。 |
| **Backhaul / fronthaul** | 回传/前传 | 回传连接无线站点与核心网络；前传连接无线射频单元与基带或集中式处理单元。 |
| **Dark fiber** | 暗光纤 | 已铺设但未配置主动传输设备的光纤，客户可以租用并自行控制传输设备，获得更高的灵活性。 |
| **Data Center / Edge DC / Housing** | 数据中心/边缘数据中心/托管 | 提供机柜、供电、制冷、连接和安全；Edge DC 更靠近用户或网络现场，Housing 指为客户设备提供机房托管。 |
| **Broadcast / DTT / DAB+** | 广播/数字电视/数字音频广播 | Broadcast 是电视和广播信号传输业务；DTT 指数字地面电视，DAB+ 指数字音频广播标准。 |
| **IoT（Internet of Things）** | 物联网 | 通过传感器、通信网络和软件连接设备并收集数据；年报把抗干扰报警网络、环境监测等列为相关场景。 |
| **OTT（Over-the-top）** | 互联网直达内容服务 | 通过互联网向用户传送电视、视频或音频内容，不完全依赖传统广播网络；年报把它列为 Broadcast 的相邻服务。 |
| **GFRP（Glass Fiber Reinforced Polymer）** | 玻璃纤维增强聚合物 | 一种比钢材更轻、耐腐蚀的塔体材料；年报中的里斯本案例属于新材料验证，不是单独财务分部。 |
| **Battery-as-a-Service** | 电池即服务 | Cellnex 为移动运营商提供备用电池系统及相关管理，以提高断电时的网络韧性；年报将其列为发展中的新服务。 |
| **V2X（Vehicle-to-Everything）** | 车与万物通信 | 车辆与道路、其他车辆、行人和交通系统之间的通信，是车联网和智慧交通的技术概念。 |
| **FRMCS** | 铁路未来移动通信系统 | 面向铁路信号和运营通信的下一代 5G 标准；Cellnex 的相关内容属于交通场景研发和项目验证。 |
| **6G / Success6G / Free6G / Q-NETWORKS** | 下一代通信及科研项目 | 6G 是 5G 之后的技术方向，后三者是研究项目名称；它们代表技术储备，不应直接当作当前收入产品。 |
| **MNO** | 移动网络运营商 | 拥有频谱和移动网络、直接向手机用户提供通信服务的公司，例如 Orange、Vodafone、Telefónica 等。 |
| **Anchor client** | 锚定客户 | 在一个国家或一组站点上贡献较大、合同期限较长的核心客户，通常是大型 MNO。 |
| **MSA / MLA** | 主服务协议/主租赁协议 | 规定长期合作的基本条款；具体站点、设备和价格通常再通过订单或项目合同落地。 |
| **SLA（Service Level Agreement）** | 服务水平协议 | 约定交付时间、可用性、故障响应、维护和质量标准，Cellnex 通过 SLA 履行长期服务责任。 |
| **RAN sharing** | 共享无线接入网 | 两家或多家运营商共同使用部分无线接入设施，可能减少重复站点，也会影响 PoP 数量和客户需求。 |
| **NOC（Network Operations Centre）** | 网络运营中心 | 负责 24/7 监控告警、能源、设备状态、故障派单和服务连续性。 |
| **Digital Twin** | 数字孪生 | 物理塔站或屋顶的三维数字副本，用来模拟天线位置、承载能力和覆盖影响，减少现场作业。 |
| **CSIRT** | 网络安全事件响应团队 | Cellnex 内部的安全监测和应急响应团队，年报称其提供 24/7 支持。 |
| **Organic growth** | 有机增长 | 不把并购、处置或汇率等组合变化作为增长来源，主要衡量既有业务本身的增长。 |
| **Street works** | 城市街道小型设施 | 设置在路灯、路边杆件或其他城市公共设施上的通信节点，通常与 Small Cells 或城市覆盖项目相关。 |
| **Planned roll-outs** | 计划部署 | 已纳入公司规划、但尚未全部建成或交付的未来站点；年报把它与现有站点分开统计。 |
| **IPO / M&A** | 首次公开发行/并购 | IPO 是公司上市发行股票；M&A 是并购交易。Cellnex 2015 年 IPO 后主要通过 M&A 和新建 BTS 扩大规模。 |
| **ESG** | 环境、社会与治理 | 评价公司气候、员工、客户、合规、治理等非财务责任的综合框架，不是 Cellnex 的独立收入部门。 |
| **CSAT（Customer Satisfaction）** | 客户满意度 | 公司对客户体验的调查指标；年报的 CSAT 8.3 是调查结果，不等同于客户留存率。 |
| **SKU（Stock Keeping Unit）** | 标准化产品单元 | 零售和产品管理中的“单品”概念；本章提到它是为了说明 Cellnex 的创新案例未必已经形成可单独售卖的标准产品。 |
| **Investment grade / BBB-** | 投资级信用评级 | 表示评级机构认为债务偿付能力达到投资级门槛；Cellnex 的 BBB- 是 S&P 和 Fitch 的评级，不是盈利指标。 |
| **Pass-through** | 转收费项目 | 能源、公用事业费等成本按合同转嫁给客户的收入和成本；剔除后更接近可比经营规模。 |
| **Revenues ex pass-through** | 剔除转收费后的收入 | 年报用于观察四条业务线真实经营规模的口径，不等同于合并利润表的全部 Operating Income。 |
| **Operating Income** | 合并利润表营业收入 | 法定报表口径的收入，可能包含能源等转收费项目；不能直接与 Revenues ex pass-through 比较。 |
| **IFRS-EU** | 欧盟采纳的国际财务报告准则 | Cellnex 编制合并财务报表所采用的会计准则体系。 |
| **CPI/RPI escalator** | 按通胀指数调价机制 | 合同价格按照消费者价格指数或零售价格指数调整；也可能使用固定比例调价，并不代表无限度涨价。 |

后文再次出现这些缩写时，不再逐一重复定义；涉及具体财务指标时，会在相应章节单独说明计算口径。

### 1.1 公司基本信息

| 项目 | 年报披露 |

| 注册办公地址 | 西班牙马德里 Calle Juan Esplandiú nº 11 [S24] |

Cellnex 的业务本质是共享、独立于运营商的通信基础设施。公司管理站址、塔桅、屋顶、机房、能源、回传、室内覆盖和相关服务；移动运营商及其他客户通常在这些设施上安装和运营自己的主动通信设备。年报因此把 Cellnex 描述为一个多运营商、多技术、跨欧洲的基础设施平台，而不是终端通信服务商或无线设备制造商。[S24]

从合并财务报表附注 1 的法律口径看，母公司的法定经营目的包括：建设和运营各类电信基础设施及网络；为自身或第三方提供、管理、营销和分销基于这些设施/网络的服务；在法律允许的合同安排下提供规划、技术支持、管理、组织、协调、监督、维护和保养；以及通过持有相关公司的股权直接或间接开展上述活动。母公司还可以作为控股公司设立或参与其他实体，集团主要经营地点为欧洲。[S24]

这一定义解释了为什么 Cellnex 的报表范围同时出现塔站公司、光纤和广播公司、融资主体、土地管理主体及少数股权平台：它们共同服务于“基础设施建设/运营 + 网络服务 + 控股管理”的法定业务边界，而不是互不相关的多元化投资。[S24]

用业务链条表示：

```text
土地/屋顶/已有站点
        ↓  购买、租赁、收购或建设
Cellnex 的被动和连接基础设施
        ↓  长期协议、项目合同、SLA
MNO、广播机构、政府和企业部署主动设备或使用网络
        ↓
语音、数据、音视频、关键通信和数字化应用
```

年报还把 Cellnex 的资产分为三个层次：**Basic TowerCo**（塔站、共址、BTS 等被动核心资产）、**Adjacent Assets**（DAS、Small Cells、光纤、回传、数据中心、广播等相邻基础设施）和 **Active Infrastructure**（RANaaS、关键通信及部分主动网络服务）。这个层次比把所有业务统称为“数字基础设施”更能解释资本密度和经营风险的差异。[S24]

### 1.2 2015-2025 年历史沿革

年报第 10 页用时间轴把 Cellnex 的历史概括为“上市、并购扩张、跨国整合、组合调整和资本回报”五个阶段。为避免把图中的不同统计口径混在一起，下面保留主要里程碑：

| 时点 | 年报里程碑 | 对公司的意义 |
|---|---|---|
| 2015 | Cellnex IPO；约 21,000 个站点；与 Bouygues 在法国签署 BTS 协议 | 从 Abertis 通信资产中形成独立上市的 TowerCo 平台 |
| 2016 | 约 24,000 个站点；继续整合西班牙和荷兰资产 | 由本土资产平台转向跨国经营 |
| 2017 | 约 58,000 个站点、约 9,000 个 BTS；成为欧洲最大的独立 TowerCo | 通过收购和建设形成规模优势 |
| 2019-2020 | 站点规模从约 61,000 增长到约 101,000；推进 Polsat 等资产交易；获得 CDP Climate Change “A List” 等可持续发展认可 | 并购扩张和 ESG 能力同步推进 |
| 2021 | 年报概括为自 2015 年以来 25 次以上整合，累计 M&A 交易约 EUR 18.8bn，并设立科学碳目标 | 规模达到约 110,000 站点，整合能力和杠杆成为核心管理议题 |
| 2022 | 约 113,000 个站点；吸引 Iliad（意大利）和 Digi（葡萄牙）等新客户；Telefonica 合同延长 30 年 | 在整合后继续拓展客户和长期合同 |
| 2023 | 法国、意大利、波兰新增约 4,500 个站点；签署 SFR 协议；进入 DJSI Europe | 继续扩张并提升可持续发展与客户覆盖 |
| 2024 | 约 112,000 个站点；获得 S&P 投资级评级；签署 Vodafone + VMO2 英国协议 | 资本结构和长期客户关系的重要性上升 |
| 2025 | 约 114,000 个站点；Towers 收入有机增长 5.5%；执行 EUR 1bn 回购；实现 100% renewable energy | 从规模扩张转向组合优化、经营效率和股东回报 |

**历史主线的研究含义。** Cellnex 不是一开始就拥有今天的跨国网络，而是用多年并购、BTS 建设和整合建立平台。并购扩大了站址和客户基础，也留下了高商誉、长期租赁、整合成本和债务。因此，阅读 2025 年报时，历史沿革必须和减值测试、杠杆、资产处置及合同续约一起看，而不能只把它当作公司宣传时间轴。[S24]

### 1.3 年报定义的四条经营业务线

年报第 11-12 页将经营部门划分为四条报告业务线。官网的 Healthcare、Transportation、Government、MNO 等属于客户场景或解决方案分类，不能替代财务分部。[S24]

| 经营部门/报告业务线 | 年报披露的主要服务 | 2025 年收入口径 | 在集团中的位置 |
|---|---|---:|---|
| **Towers** | Co-location、Build-to-Suit、站点配置、工程与安装、站址运维 | 约 EUR 3,225m；约 81% 的 Revenues ex pass-through | 被动基础设施核心，收入和现金流主引擎 |
| **DAS, Small Cells and RAN-as-a-Service** | DAS、Small Cells、RANaaS、Mission Critical Networks and solutions、部分 O&M | 约 EUR 272m；约 7% | 室内、密集区和主动网络相邻业务 |
| **Fiber, Connectivity and Housing Services** | FTTT、光纤传输、回传/前传、数据中心和边缘连接 | 约 EUR 234m；约 6% | 支撑塔站、5G 和边缘计算的连接层 |
| **Broadcast** | 面向 TV Service Providers、Radio Service Providers 的电视、广播、网络运维和媒体连接 | 约 EUR 264m；约 7% | 稳定的公共服务型和区域性业务 |

这里的约 EUR 3,995m 是年报第 12 页的 **2025 Revenues ex pass-through** 分解，四条业务线加总约为该数。合并利润表中的 Operating Income 是 EUR 4,418m，包含能源、公用事业费及其他 pass-through 项目，后文财务章节会单独解释两种口径。[S24]

#### Towers：基础设施核心

年报把 Towers 描述为向 MNO、其他无线通信运营商和宽带网络运营商提供被动基础设施访问的业务。核心对象包括宏站、屋顶、特殊站址、土地、机房、供电、围栏/安全、微波或光纤回传以及可在边缘处理数据的空间。[S24]

- **Co-location**：客户把主动天线、射频和基带设备放置在 Cellnex 站点上。
- **Build-to-Suit**：客户需要新位置时，Cellnex 管理许可、建设、供电连接、运营和维护。
- **Engineering Services**：包括现场勘察、结构计算、设计、站点适配、安装、调试和技术升级。
- **站点改造与技术升级**：应对 5G、天线替换、RAN vendor swap、带宽扩展和网络配置变化。
- **站点合理化**：运营商合并后拆除重复基础设施，把需求迁移到共享站点。

2025 年报披露集团管理约 `111,752` 个电信站点、约 `180,856` 个 PoPs；如果包括广播站点，站点总数为 `113,801`。年报另称包括计划到 2030 年的 rollout 后约为 120,000，这些是不同统计范围，不能直接合并为同一个“当前塔数”。[S24]

#### DAS、Small Cells、RANaaS 与 Mission Critical

这条业务线服务于宏站覆盖不足或容量密集的场景，包括体育场、机场、购物中心、办公楼、酒店、交通枢纽、隧道、停车场和铁路站点。DAS 通过分布式天线提供多运营商室内覆盖；Small Cells 以小功率节点补充城市局部容量；RANaaS 在波兰把主动无线发射和传输服务叠加在塔站之上。[S24]

Mission Critical Networks 面向警察、消防、救护、政府、交通和海事等公共安全客户，强调全国覆盖、可靠性和高可用性。2025 年西班牙停电期间，Cellnex 披露其广播和应急通信保持运行，移动服务在 24 小时内恢复约 98%；这是公司运营韧性能力的案例，不应直接等同于独立业务收入。[S24]

#### Fiber、Connectivity、Housing 与 Edge

年报把光纤定位为连接塔站、Small Cells、室内系统和边缘计算设施的基础。服务包括 FTTT、fronthaul/backhaul、光纤传输、企业或运营商专线，以及数据中心/边缘机房的 housing。法国 Nexloop 提供全国性中立 dark-fiber 网络，西班牙、波兰和法国拥有较大的光纤网络。[S24]

#### Broadcast

Broadcast 主要在西班牙和荷兰提供 DTT 电视、广播、网络运维、媒体内容连接和相关 OTT 服务。年报披露广播站点约 `2,049` 个；西班牙商业广播 DTT 许可延长至 2040 年，商业广播合同续约至 2030 年；荷兰完成全国 DAB+ 部署。[S24]

### 1.6 2025 年公司定位的年报原话与研究归纳

年报对自身定位的关键词可以归纳为：

- **欧洲领先的无线通信基础设施提供商**：以 10 国、113,801 个站点和跨国客户关系为规模基础。
- **Neutral shared infrastructure**：多运营商、多技术共享，帮助 MNO 提高部署速度、降低重复建设成本和改善资本回报。
- **Beyond towers**：广播、应急服务网络、DAS/Small Cells、光纤、数据中心、IoT 和智能服务扩展了传统塔站的价值链。
- **Industrial transformation**：通过土地收购和租约重谈、集中采购、供应商优化、AI 工具、Digital Twin 和网络安全提高每个站点的运营效率。
- **Financial flexibility and shareholder returns**：2025 年执行 EUR 1bn 回购，组合处置和债务管理服务于核心通信基础设施和资本回报。[S24]

年报第 17 页还给出了公司判断经营底座的三个量化特征：预计 2030 年全球数据流量将因 5G、6G、视频和 AI 服务而超过当前水平的两倍；集团拥有十个成熟欧洲市场的 `16` 个锚定客户；长期合同储备超过 `EUR 100bn`。后两项是公司口径，合同储备依赖合同期限、续约假设和保护条款，不能简单等同于全部不可撤销订单。[S24]

**本章研究判断。** Cellnex 的基础经营单元不是“一个塔”，而是“一个可持续控制的站址 + 一个或多个客户 PoP + 长期服务合同 + 土地/能源/运维能力”。四条业务线中，Towers 提供规模和现金流底座，DAS/Small Cells/RANaaS、Fiber/Connectivity/Housing 和 Broadcast 提供相邻能力；但它们的主动设备、资本强度和合同结构不同，后续分析应分别拆开，而不能仅以“数字基础设施”一个标签概括。

### 1.8 客户、员工和服务组织

年报将 Cellnex 描述为 MNO 和其他连接服务商的长期基础设施伙伴，并列举 Iliad、Vodafone、Hutchison、Orange 和 Telefónica 等欧洲主要运营商作为长期合作对象。公司披露 2025 年客户满意度 CSAT 为 `8.3`，调查参与率 `71%`，其中 `52%` 的客户表示“非常满意”。这些是公司调查指标，不等同于外部客户留存率或合同续约率。[S24]

员工是这类基础设施平台把合同变成收入的执行环节。年报披露：

- 2025 年集团有 `2,511` 名专业人员，覆盖工程、NOC、客户、土地、项目、采购和集团职能。
- Pulse Survey 参与率为 `85%`，员工参与度为 `72%`。
- Cellnex 在西班牙获得 Top Employer Certification，并计划向集团范围扩展。
- 现场工程、供应商和客户验收共同构成服务质量体系；年报披露集团约有 `1.2m` 次站点物理访问、超过 `152k` 次维护活动和约 `16k` 次成功交付的 provision requests。[S24]

客户关系的基本经营特征也应和“客户满意度”分开看。年报称 Cellnex 拥有 `16` 个锚定客户、超过 `EUR 100bn` 的长期合同储备，并依靠全有或全无（all-or-nothing）条款、对 RAN sharing 的限制等合同保护来降低运营商合并带来的去站风险。2025 年的代表性动作包括：MasOrange 在西班牙把合同延长至 2038 年，并保留到 2048 年的十年续约选择；Telefónica 计划新增 110 个 physical PoPs 并激活最多 3,000 个 RAN-sharing DIGI PoPs；荷兰 Odido 延长长期合作；意大利 Fastweb+Vodafone 续约 12 年；西班牙和葡萄牙的 Securitas Direct 续约五年。它们说明 Cellnex 的收入基础是“长期合同 + 增量 PoP/升级”，而不是一次性建设订单。[S24]

这说明 Cellnex 不是只持有塔站并收租的“被动资产壳”。它需要持续配置工程师、站点运营人员、租约和客户团队，才能完成新 PoP、升级、维护、能源、网络安全和去站项目。后续分析利润率时，应把租赁资产的经营杠杆与这套服务组织的成本同时考虑。

- **交通和车联网**：Metro Bilbao 的私有 5G 轨道信号验证、FRMCS 铁路标准、跨境 5G corridor、V2X 应急车道清理和车辆排放实时测量项目。[S24]

这些案例说明年报中的“产品”并不都是已经形成大规模独立收入的标准化 SKU。它们可以是长期塔站服务、连接网络、工程项目、政府关键通信或研发验证项目；研究时应区分已规模化的核心 Towers 与处于扩展、验证或相邻业务阶段的技术能力。

#### 2.1.3 收入口径：Services (Gross)、Operating Income 与 Revenues ex pass-through

- **Services (Gross)**：四条业务线服务收入的总额，同时包含 Utility Fee。2025 年 Utility Fee 为 EUR 128.892m，2024 年为 EUR 132.966m；它主要是能源费用随服务费向客户转收的部分。

### 2.2 Towers：核心塔站业务

#### 2.2.1 年报定义和运营方式

2025 年报把 Towers 称为集团按收入计算最大的业务线。它向 MNO、其他无线通信运营商和宽带网络运营商提供一整套**被动基础设施访问服务**，使这些客户可以把自己的宏小区主动设备安装在 Cellnex 的基础设施上，并向终端客户提供通信服务。Cellnex 是中立承载方，通常不拥有客户的主动无线设备和频谱，也不直接向个人手机用户收取移动通信费。[S24]

Towers 的运营链条包括：

- **站址与被动设施**：土地、屋顶、塔桅、机房/机柜空间、围栏、安全、供电、备用电源及可用的微波或光纤接入。大部分土地和屋顶通过第三方租赁、转租或其他长期合同控制。
- **Co-location（共址）**：客户把天线、射频、基带、微波等主动设备放到现有站点；Cellnex 按站址、设备、空间、容量和服务等级收费，多租户可以复用已有土地、塔桅、供电、监控和维护。
- **Build-to-Suit（BTS）**：客户提出覆盖或容量需求后，Cellnex 负责选址、许可、设计、建设、供电、验收和长期运营；BTS 通常在合同签订后建设，前期只有锚定客户，未来可增加共址租户。
- **Build-to-Fit/站点配置**：对既有站点进行结构加固、机房、供电、天线位置、带宽、RAN vendor swap 或 5G 配置升级。
- **Engineering Services**：现场勘察、适配、结构计算、工程设计、安装、调试、Works & Studies 等。年报把它作为独立收入流和履约义务；它既可能形成服务收入，也可能作为扩张资本开支的一部分执行。
- **合理化和去站**：在 MNO 合并、RAN sharing 或网络重叠时拆除重复基础设施；同时在战略位置建设新站，改善 4G/5G 覆盖、信号质量和网络密度。

年报列出的 Towers 收入来源为：锚定客户和次级租户的年度基础费；按 CPI/RPI、通胀或固定比例计算的 escalator；新的第三方共址及特殊连接项目；5G rollout 引起的站点配置变化；以及 Engineering Services。主要成本通常包括能源、土地/屋顶费用、物业税、维修和维护。MNO 通常维护自己的主动设备，但在某些合同中也会把主动设备维护外包给 Cellnex。[S24][S25]

### 2.3 DAS、Small Cells 与 RAN-as-a-Service

#### 2.3.1 名词和运营方式

- **DAS（Distributed Antenna System，分布式天线系统）**：把多个分布式天线接到共同信号源，在一个建筑或区域内提供多运营商无线服务；可承载 2G、3G、4G、5G 等不同技术和频段。
- **Small Cells**：功率较低、覆盖半径较小的无线节点，用于补充宏站无法经济覆盖的局部容量和覆盖，尤其适合密集城市和室内场景。
- **RANaaS（RAN-as-a-Service）**：在波兰，Cellnex 在被动塔站之外提供主动无线发射和传输服务；年报表示将先巩固波兰的商业模型，再考虑向其他地点扩张。
- **PPDR/Mission Critical**：面向警察、消防、救护、政府、交通和海事等公共安全部门的关键通信网络，包括 TETRA、4G/LTE 等主动基础设施服务，强调全国覆盖、可靠性和高可用性。
- **O&M（Operation & Maintenance）**：运营和维护，可覆盖站址、天线节点、主动设备、告警、现场工程和服务质量。
- **Smart City/IoT**：以连接、传感器、数据采集和城市基础设施管理为基础的智慧城市和物联网服务；年报把它作为该业务线的其他服务，而不是单独报告分部。

该业务线主要解决宏站在体育场、隧道、医院、机场、购物中心、办公楼、交通枢纽、地下空间和高密度城区中无法充分提供覆盖或容量的问题。Cellnex 可以负责基础设施取得、设计、安装、调试、O&M、监控和服务质量保证；在部分 DAS 和 RANaaS 项目中还运营客户或自有的主动网络设备。[S24][S25]

### 2.4 Fiber、Connectivity and Housing Services

#### 2.4.1 名词和运营方式

- **FTTT（Fiber-to-the-Tower）**：以光纤把塔站接入传输网络，为高容量 4G/5G 回传和未来网络升级提供基础。
- **Backhaul/Transmission**：把站点或无线接入节点连接到核心网络，可使用光纤、微波或其他传输方式。
- **Fronthaul**：把集中式或分布式无线接入单元与天线/无线单元连接，常用于 5G、DAS 和 Small Cells 架构。
- **Connectivity/专线**：向 MNO、固定网络运营商、政府、企业和其他客户提供传输、专用连接或农村地区的网络接入。
- **Housing/Edge DC**：在靠近网络边缘的位置提供机柜、能源、冷却、连接、安全和运维，让客户把计算或网络设备部署在靠近用户和站点的机房。

年报将该业务线定义为把塔站、DAS、Small Cells 和边缘计算设施连接起来的“数据传输层”。2017 年收购的荷兰 Alticom 拥有高塔和数据中心资产；法国与 Bouygues Telecom 合作发展全国性光纤传输网络。战略上，Cellnex 一方面兑现已承诺的网络部署，另一方面利用已有站址向锚定客户提供共享高速传输，只在符合客户利益和站址价值的项目上选择性投资。[S24]

### 2.5 Broadcast：电视、广播与网络运维

#### 2.5.1 业务定义和合同运营方式

Broadcast 主要在西班牙和荷兰经营。年报列出的服务包括电视和广播信号的分发与传输、广播网络的运营和维护、媒体内容连接、OTT 广播服务及其他相关服务。西班牙 Cellnex 是全国性 DTT（Digital Terrestrial Television，数字地面电视）服务的重要运营商，并拥有全国私营电视 MUX（multiplex，多路复用频道）领域的独特技术和市场经验；荷兰业务同时覆盖广播和数字无线电基础设施。[S24]

- **DTT**：把数字电视信号通过地面发射网络传送到家庭和公共接收系统。
- **MUX**：多路复用器，把多个电视服务组合在一个广播承载中；Cellnex 按 MUX/承载和网络服务向电视服务商收费。
- **FM、DAB/DAB+**：模拟调频和数字音频广播服务，依靠高塔、发射机、供电、监控和运维网络提供覆盖。
- **Broadcast O&M**：发射设备、站点、网络监控、维护、内容连接和可用性保障。

Broadcast 的商业特征是公共服务属性强、站点复用率高、合同期限通常较长且续约率较高。2025 年报披露，西班牙商业广播 DTT 许可延长至 2040 年，商业广播合同续约至 2030 年；公司计划在西班牙和荷兰当前市场范围内保持强势地位、通过效率提升保护现金流。年报并未把该业务的能源、站点租金、人员或网络成本单独分配出来。[S24]

### 3.5 财务指标计算

#### 3.5.1 原始科目到分析指标的映射

Cellnex 的报表有两个容易造成机械误算的特点：一是损益表中的 `Operating income` 是经营收入而不是营业利润；二是债务、租赁和资本开支同时存在 IFRS 科目与公司 APM 口径。以下映射是本章所有衍生指标的底层口径：[S24][S25][S26]

| 分析字段 | 原始披露/计算 | 经济范围与限制 |
|---|---|---|
| Revenue | `Services + Other operating income = Operating income` | Cellnex 的 `Operating income` 在本报表中是收入小计 |
| Calculated EBITDA | `Operating profit + D&A` | 未调整 EBITDA；不加回减值、处置和管理层定义的非经常项目 |
| Adjusted EBITDA | 公司 APM 桥接值 | 加回减值、处置、部分非经常和非现金项目；不是 IFRS 指标 |
| EBITDAaL | `Adjusted EBITDA - ordinary lease instalments` | 扣除正常经营租赁付款后的公司 APM，适合观察塔站租赁后的经营能力 |
| Balance-sheet debt incl. leases | 流动及非流动借款 + 流动及非流动租赁负债 | 不含 Omtel 递延收购款等公司 APM 调整 |
| Company Net Financial Debt | 公司 Gross Financial Debt - 现金 - Other financial assets | 公司 APM；Gross Financial Debt 包含债券、贷款、租赁及 Omtel 递延收购款 |
| Cash flow after capex | `CFO - cash purchases of PPE and intangibles` | 研究者计算，不等于公司 FCF |
| Company FCF | `RLFCF - Expansion Capex - BTS Capex and Remedies` | 公司 APM；M&A Capex 和 Divestments 位于 FCF 之后，不直接构成 FCF |
| Parent ROE | 归母净利润/平均归母权益 | 归属口径一致，不使用包含 NCI 的总权益 |
| ROA | 合并净利润/平均合并总资产 | 资产和利润均包含 NCI 的经济权益 |

| Gross margin | 损益表按费用性质列示，没有一致、可验证的 Cost of revenue/Gross profit |
| CFO / net income | 三年合并净利润均为负，倍数没有可解释性，应分析净利润到 CFO 的桥接 |
| EBIT interest coverage | `Net financial loss` 包含租赁利息、应计/未付利息、摊销融资成本等，不等于纯净现金利息 |
| DIO、DPO、Cash Conversion Cycle | 未披露一致的 Cost of revenue/采购额，贸易及其他应收应付款还含非纯贸易项目 |
| ROIC | 税前持续亏损且税收收益含大额一次性/递延项目，缺少可防御的正常化税率和投入资本边界 |

严格勾稽共执行 15 项检查，2023-2025 年每年均满足：资产 = 负债 + 权益；合并净利润 = 归母 + NCI；期初现金 + 净变动 = 期末现金；CFO + CFI + CFF + FX = 净现金变动；现金流量表期末现金 = 资产负债表现金。输入科目均记录了原始标签、报表、文件和印刷页码，没有以空白代替零。[S24][S25][S26]

### 3.6 盈利能力与经营杠杆

本节以 3.5.3 的盈利与回报指标表为起点，再用损益表项目解释指标变化。

**第一，收入仍增长，但增速已从扩张期回落。** 经营收入由 EUR 4,049.223m 增至 EUR 4,418.346m，2024 年增长 7.51%，2025 年仅增长 1.50%；服务收入增速从 7.00% 放缓至 1.23%。这说明 2025 年的重点已经从并购驱动的规模扩张转向存量资产提效、合同调价、共址和资本纪律。[S24][S25][S26]

**第二，法定经营利润高度受减值、处置和控制权变化影响。** 2024 年 EUR 509.001m 减值使经营利润率由 9.24% 降至 4.52%；2025 年减值降至 EUR 90.502m，同时确认 EUR 67.289m 丧失控制权收益，经营利润率回升至 10.77%。因此 2024 年不是核心塔站经济性按同等幅度恶化，2025 年也不是全部来自经常性经营改善。[S24]

**第三，由法定报表计算的未调整 EBITDA 与公司 Adjusted EBITDA 必须分开。** `Operating profit + D&A` 得到的未调整 EBITDA 分别为 EUR 2,993.284m、EUR 2,805.154m 和 EUR 3,148.938m；与公司 Adjusted EBITDA 的差额分别为 EUR 15.130m、EUR 444.744m 和 EUR 168.339m。2024 年差额最大，核心原因是减值、处置及公司定义的非经常/非现金调整。Adjusted EBITDA margin 三年稳定在约 82%-83%，并不意味着 IFRS 经营利润率同样稳定。[S24][S25][S26]

**第四，扣租赁后的经营效率确有改善。** EBITDAaL margin 从 58.95% 升至 62.17%，改善幅度大于 Adjusted EBITDA margin，说明正常租赁付款相对可比收入的负担下降，符合公司“proactive land management”和运营效率提升的叙述。它仍是公司 APM，必须结合租赁负债和实际租赁现金支出判断，不能替代 CFO。[S24]

**第五，会计盈利仍未修复。** 净财务损失从 EUR 807.849m 扩大至 EUR 925.220m，2025 年归母净亏损达到 EUR 360.776m；正确匹配归属口径后，2025 年 ROA 为 `(0.82%)`，Parent ROE 为 `(2.75%)`。资产周转率虽从 0.09x 升至 0.10x，但仍体现出重资产、长寿命和收购形成无形资产占比较高的结构。Cellnex 没有可一致计算的 Gross margin，不能用 Adjusted EBITDA margin 代替毛利率。[S24][S25][S26]

### 3.7 资产负债表、杠杆与流动性

本节对应 3.5.4 的资产负债结构表和杠杆指标表，分别观察资产沉淀、带息义务、权益缓冲和短期流动性。

总资产三年减少约 EUR 2.30bn，但 PPE 从 EUR 11.67bn 增至 EUR 12.70bn，说明有形基础设施仍在投入；无形资产从 EUR 24.70bn 降至 EUR 21.66bn，反映摊销、处置和减值的累计影响。2025 年持有待售资产降至 EUR 496.803m，也与资产处置推进相符。[S24][S25][S26]

净权益率从 2024 年 35.09% 降至 2025 年 31.68%。2025 年归母权益减少 EUR 2.04bn；除归母亏损外，现金流量表还显示 EUR 1,000.355m 库存股收购，但资产负债表中的期末库存股账面余额只有 EUR 268.450m。现金支出、期末库存股余额以及股本和股本溢价的变动需要结合权益变动表整体解释，不能把 EUR 1.000bn 现金支出直接等同于期末库存股余额。[S24]

公司 Net Financial Debt 从重列后的 EUR 20.618bn 增至 EUR 20.818bn，两年只增加约 EUR 200m；Company NFD/Adjusted EBITDA 从 6.85x 降至 6.28x，主要来自 Adjusted EBITDA 增长，而不是净债务大幅下降。由于公司 NFD 包含租赁负债，Adjusted EBITDA 却在正常租赁付款前，研究者进一步用 NFD/EBITDAaL 观察租赁匹配后的杠杆，得到 9.56x、8.70x 和 8.38x。趋势改善，但绝对水平仍高。[S24][S25]

资产负债表借款加租赁负债占资产比重从 48.52% 升至 52.07%，Debt incl. leases/equity 则由 1.42x 升至 1.64x；后者在 2025 年明显上升，是债务增加约 EUR 446m 与总权益减少约 EUR 2.00bn 共同作用的结果。该资产负债表口径与公司 Gross Financial Debt/Net Financial Debt APM 不同：公司口径还纳入 Omtel 递延收购款并扣除特定 Other financial assets。分析债务时应优先使用公司有完整勾稽的 APM，再用资产负债表口径解释组成，不能混称为同一个“净债务”。[S24][S25]

简单流动性指标明显走弱：流动比率由 0.77x 降至 0.51x，现金比率维持约 0.30x。对基础设施公司而言，长期合同和稳定经营现金流可以部分弥补低流动比率，但 2025 年流动银行借款、流动衍生工具和流动准备均上升，仍需结合债券到期表、未使用授信、利率套期保值和未来资产处置现金一起判断短期偿债能力。

### 3.8 现金流、资本开支与现金转换

本节对应 3.5.5：先根据现金流向表区分经营、投资和融资来源，再解释现金转换和资本开支指标。

经营活动现金流三年保持在 EUR 2.07-2.31bn，CFO margin 稳定在约 51%-53%；现金利息覆盖约 2.75x-3.09x。2025 年 CFO 同比小幅下降 EUR 20.527m，贸易应收款释放 EUR 124.564m，但其他流动资产/负债流出 EUR 79.820m、所得税支付增至 EUR 227.303m。Accrual ratio 连续为负且 2025 年为 `(6.16%)`，说明现金显著高于会计利润，主要来自巨额折旧摊销和其他非现金调整，而不是净利润本身质量强。[S24][S25][S26]

法定现金流量表口径的 `CFO - PPE及无形资产购置` 从 2023 年 EUR `(126.003)m` 改善到 2024 年 EUR 276.237m、2025 年 EUR 525.822m，覆盖率从 0.94x 升至 1.30x，Capex intensity 同期从 54.18% 降至 39.84%。改善同时来自 CFO 稳定和购置现金支出从 EUR 2.194bn 降至 EUR 1.760bn，不能只归因于收入增长。D&A/购置支出由 1.19x 升至 1.52x，表明会计资产消耗显著高于当期现金购置；但 D&A 包含收购形成无形资产摊销、历史资本开支和租赁结构，不能单凭该比率断言维护不足。

公司 FCF 与上述简单计算不是同一指标。RLFCF margin 从 38.16% 升至 43.29%，Company FCF margin 从 3.71% 升至 7.93%，但两者之间仍有很大落差。公司从 Adjusted EBITDA 出发形成 RLFCF，再扣除 Expansion Capex 和 BTS Capex/Remedies：2024 年 FCF 增加 EUR 177.359m，来自 RLFCF 增加 EUR 250.941m，部分被 Expansion Capex 多支出 EUR 49.126m 及 BTS/Remedies 多支出 EUR 24.456m 抵消；2025 年 FCF 仅增加 EUR 22.624m，RLFCF 增加 EUR 116.532m、Expansion Capex 少支出 EUR 60.046m，但 BTS/Remedies 多支出 EUR 153.954m。由此可见，2025 年经常性现金生成继续改善，但承诺建设项目吸收了大部分增量。[S24][S25]

投资现金流净流出从 EUR 1.592bn 降至 EUR 0.749bn，除了购置支出下降，还因为持有待售资产处置收入从 EUR 630.749m 增至 EUR 1,052.900m。资产处置改善 CFI、现金和净债务，但公司 FCF 定义在 M&A Capex/Divestments 之前，因此不能把处置收入说成公司 FCF 上升的直接组成部分。这是判断“内生现金改善”与“资产组合收缩释放现金”的关键分界。

融资活动连续为净流出：2024 年为 EUR `(1,294.295)m`，2025 年为 EUR `(1,113.471)m`。2025 年公司支付 EUR 1,000.355m 收购库存股，仍实现现金净增加 EUR 410.209m，依赖稳定 CFO、较低购置支出和 EUR 1.053bn 处置收入共同覆盖。若后续处置收入下降，Company FCF、基于法定现金流量表计算的 cash flow after capex 与债务到期之间的覆盖关系会成为更严格的股东回报约束。

### 3.9 三年结论与局限

**核心经营。** 收入增速由 7.51% 放缓至 1.50%，但 Adjusted EBITDA margin 稳定、EBITDAaL margin 扩张，说明存量塔站、租赁管理和运营效率正在抵消规模增速放缓。2024 年减值造成的法定利润低点并不等同于经常性塔站业务崩坏。

**会计盈利。** 三年均亏损，2025 年归母净亏损扩大至 EUR 360.776m；高折旧摊销、净财务损失和税项使 ROA、Parent ROE 继续为负。现金生成强于净利润不意味着折旧和融资成本可以忽略，它们分别代表历史资本投入的消耗和高杠杆的真实经济负担。

**现金与资本纪律。** RLFCF、Company FCF 和基于法定现金流量表计算的 cash flow after capex 均改善，但含义不同。最有价值的信号是 CFO 稳定、维护后经常性现金增长、资本购置覆盖率超过 1；需要警惕的是 FCF 增量仍会被 BTS 承诺、扩张资本开支和股东回报快速吸收。

**资产负债表。** 公司 NFD 近两年基本横盘，杠杆倍数因 EBITDA/EBITDAaL 增长而下降，不是因为债务绝对额明显减少。流动比率降至 0.51x、权益率降至 31.68%、租赁匹配后的 NFD/EBITDAaL 仍为 8.38x，因此“去杠杆取得进展”与“杠杆已经轻”是两个完全不同的判断。

**局限。** 三份年报没有提供四条业务线各自完整的成本、资产、债务、EBITDA 或现金流，集团层面的利润率和杠杆不能反推业务线回报；损益表没有可一致识别的 Cost of revenue，不能计算 Gross margin 和完整营运资本周期；亏损和异常税收收益使 ROIC 正常化缺乏可靠基础；2023 债务 APM 还存在后续定义变化。后续估值应补充债券到期表、固定/浮动利率、未使用授信、土地与租赁现金承诺、Maintenance/Expansion/BTS 项目回报，以及国家/客户合同期限和分部资本开支。[S24][S25][S26]

### 4.3 DAS、Small Cells 与 RANaaS

这条业务线解决宏站无法经济覆盖的场景：体育场、机场、医院、购物中心、办公楼、地铁、隧道、地下空间、历史街区和高密度城区。[S01][S07]

- **DAS（Distributed Antenna System）**：多个分布式天线连接到共同信号源，在特定建筑或区域提供多运营商无线覆盖。
- **Small Cells**：低功率、小范围节点，补充宏站容量和局部覆盖。
- **RANaaS**：在波兰把主动网络发射和传输服务叠加在被动塔站之上；公司表示先巩固波兰，再考虑扩大地域。
- **PPDR / Mission Critical**：面向公共安全、政府、交通、海事等客户交付 TETRA、LTE/4G 或 5G 关键通信网络。
- **O&M**：为客户或自有网络提供基础设施和设备运维。
- **IoT / Smart Services**：从传感器、Sigfox/LoRaWAN 网络到 SmartConnectivity、SmartBrain 和 SmartSolutions 的端到端服务。[S11][S12]

FY2025 年报披露约 `15,509 antenna nodes`；官网公司简介又称 `+7,500 DAS nodes and Small Cells installed`，详细产品页的逐国统计还采用不同范围。由于时间、对象和统计层级不一致，这些数字不应简单相加。[S01][S04][S07]

### 4.4 Fiber、Connectivity 与 Housing

这条业务线把站点从“有位置”连接到“有传输和计算能力”：

- **FTTT（Fiber to the Tower）**：以光纤连接宏站，为 5G 和高容量回传提供基础。
- **Backhaul / transmission**：用光纤、微波或卫星连接网络节点。
- **Enterprise leased lines**：向 MNO、固定网络运营商、政府、企业和农村客户提供专线。
- **Edge data centres / housing**：在靠近网络边缘的位置提供机柜、能源、连接、冷却、安全和运维，并可按 Tier 1-4 SLA 交付。[S08][S09]

H1 2026 该业务线有机增长 7.8%，公司主要归因于法国 Nexloop 部署。但法国数据中心处置后，官网列示的数据中心位置与当前经济权益范围不一定一致，不能直接据此估算存量收入或估值。[S02][S09]

### 4.5 Broadcast

Broadcast 主要在西班牙和荷兰提供电视、广播信号的分发和传输、广播网络运行维护、媒体内容连接和 OTT 相关服务。[S01][S10]

该业务可以复用 Cellnex 的高塔、供电、监控、NOC 和维护网络，FY2025 Operating Income 为 EUR 264m，H1 2026 有机增长仅 0.5%。因此它更接近成熟、稳定的区域性现金流业务，而不是高增长的核心塔站扩张业务。[S01][S02]

| 政府与应急机构 | 高可用、保密、群组通信、视频 | TETRA/LTE/5G PPDR、IoT | SIRESP 和 Mission Critical [S11][S19] |
| 广播机构 | 全国或区域信号与高可用运维 | DTT、广播、媒体连接、NOC | Broadcast 页面 [S10] |
| 土地/屋顶业主 | 资产变现、长期租约 | 买地、长租、续约、租金资本化 | Landlords 页面 [S16] |

`Ready to Connect` 是站址发现和商业转化的数字入口，不是独立财务分部。官网没有披露其使用量、转化率或独立收入。[S15]

## 五、行业需求与供给：为什么需要中立 TowerCo

> **分析时点：2026-08-07。** 本章先站在行业而非 Cellnex 单一公司的角度，解释移动通信基础设施的需求从哪里来、为什么会传导到站址和中立宿主，以及有效供给为何受位置、许可、土地、电力、回传、合同和资本约束。下一章再回答 Cellnex 如何利用这些行业条件形成自己的收入和现金流。

**结论先行：**

1. 手机用户的流量是上游需求，不是 TowerCo 的直接订单；MNO 必须先选择增加站点、设备占用、室分或回传，需求才会传到基础设施公司。
2. 网络需求应拆成覆盖、容量、室内/特殊场景和韧性四类，它们对应的宏站、屋顶、Small Cell、DAS、光纤和能源方案不同。
3. 中立 TowerCo 存在的经济基础，是多个 MNO 可以共享被动设施，却继续分别控制频谱、主动设备、核心网和终端客户。
4. 有效供给不是钢塔数量，而是特定搜索区域内合法、可承载、有电、有回传、能施工并可长期使用的位置。
5. 欧洲一般 5G 覆盖已较高，但中频容量型覆盖仍有缺口；流量增长也高度局部化，因此不能用欧洲平均流量直接推导塔数。[S28][S29]
6. 存量共址、存量改造和新建 BTS 的供给弹性、资本强度和交付周期完全不同，必须分别分析。
7. 站址稀缺和长合同形成壁垒，但 MNO 自建、网络共享、去站、技术升级及竞争监管会限制 TowerCo 的定价权。

### 5.1 先拆产业链：Cellnex 位于哪一层

移动通信网络同时需要频谱、主动设备、被动基础设施和传输网络。Cellnex 主要处于被动基础设施层，并向室内覆盖、主动网络服务、光纤回传和关键通信等相邻层延伸；它不直接向普通消费者出售移动套餐，也不制造基站主设备。[S01][S04][S06]

| 产业链层级 | 主要参与者 | 核心投入与风险 | 与 Cellnex 的接口 |
|---|---|---|---|
| 终端需求与应用 | 消费者、企业、政府、云与内容平台、交通/场馆/医院 | 视频、云、AI、IoT、移动办公、公共安全带来流量、覆盖、时延和可靠性要求 | 不直接付费给 Cellnex，但决定网络负荷在哪里、何时发生 |
| 频谱与规则 | 各国政府、频谱管理机构、规划/建设/环保部门 | 分配频谱，设定覆盖义务、功率和电磁规则，审批站址与工程 | 决定 MNO 可用的频段，也决定站址能否合法建设和升级 |
| MNO 与主动 RAN | Vodafone、Orange、Telefónica、Iliad、Three 等；设备商 | 频谱、基带、射频、天线、软件、核心网、客户获取和服务质量 | MNO 是 Towers 的核心客户；决定自建、共享、向 TowerCo 租用或去站 |
| 被动通信基础设施 | Cellnex、其他 TowerCo、MNO 自有塔、屋顶/土地业主、共享网络合资公司 | 土地/屋顶权利、塔桅、机房、供电、安防、许可、维护 | Cellnex 的核心层：共址、BTS、站点改造、工程和运维 |
| 室内及特殊场景 | 中立宿主、DAS/Small Cell 集成商、物业和交通业主 | 室内布线、分布式天线、低功率节点、隧道/场馆施工、跨运营商协调 | Cellnex 的 DAS、Small Cells、交通覆盖和关键通信业务 |
| 传输与计算 | 光纤运营商、批发网络、数据中心、微波/卫星服务商 | FTTT、回传、专线、机柜、电力、冷却和边缘节点 | Cellnex 的 Fiber、Connectivity、Housing；也是每个无线站址可用性的投入 |

这条链的需求传导可概括为：

```text
终端流量、覆盖与可靠性要求
  -> MNO 的覆盖、容量、时延和 SLA 缺口
  -> 频谱、主动设备、站点密度、室内系统和回传之间的技术选择
  -> MNO 在自建、共享、TowerCo 租用之间的经济选择
  -> Cellnex 的新增共址、设备改造、BTS、DAS/Small Cell、光纤或运维收入
```

**分析判断。** 这是研究 Cellnex 需求时最重要的过滤器：数据流量增长只是上游驱动，不能直接等同于塔数或收入增长。若运营商通过更多频谱、更高频谱效率、天线升级或网络共享消化流量，Cellnex 可能只获得较小的站点改造费，甚至没有新增 PoP；只有需求最终落到新的站址占用、更多设备、站点密集化、室内系统或回传连接时，才会形成可观的基础设施收入。

### 5.2 为什么 MNO 会选择中立 TowerCo，而不是全部自己建设

MNO 理论上可以自己租地、建塔和维护网络。TowerCo 模式之所以产生，不是因为 MNO 做不到，而是因为某些被动基础设施具有“可共享、长寿命、本地许可复杂、与零售差异化关系较弱”的特征，适合交给独立平台集中运营。

#### 5.2.1 MNO 的五项经济权衡

| 决策因素 | 自建/自持 | 向中立 TowerCo 采购 | 哪一方可能更优 |
|---|---|---|---|
| 前期资本 | MNO 自己承担土地、塔和配套 CapEx | Cellnex先投入，MNO 支付长期服务费 | 取决于双方资本成本和合同价格 |
| 上市速度 | MNO 自行组织选址、许可和施工 | 复用 Cellnex 存量站或其本地团队 | 有合适存量站时 TowerCo 通常更快 |
| 资产控制 | MNO 对位置、容量和改造有更直接控制 | 受 MSA、站点规则、排期和共享安排约束 | 战略关键位置可能倾向自持或更强合同权利 |
| 共享经济 | 单一 MNO 承担固定成本，除非自行引入租户 | 多家 MNO 共用土地、塔桅和维护 | 多租户地点更有利于中立宿主 |
| 长期成本 | 没有 TowerCo 服务加价，但承担全周期运营和更新 | 支付长期、调价的服务费，减少内部管理 | 必须比较全生命周期 TCO，不能只看当年 Opex |

共享经济可以用一个极简对比理解：

```text
不共享：
MNO A -> 一份土地/屋顶 + 一座塔 + 一套供电安防维护
MNO B -> 一份土地/屋顶 + 一座塔 + 一套供电安防维护
MNO C -> 一份土地/屋顶 + 一座塔 + 一套供电安防维护

中立宿主共享：
MNO A 的主动设备 ┐
MNO B 的主动设备 ├-> 一处土地/屋顶 + 一座共享塔 + 一套基础运维
MNO C 的主动设备 ┘
```

社会层面节省的是重复的被动基础设施；MNO 仍保留各自频谱、天线/射频配置、核心网和用户竞争。Cellnex 的经济机会来自：它收取多份站点服务费，却能复用一部分地租、塔桅、安防、NOC 和维护成本。能否真正降低总成本，取决于第二、第三租户是否出现，以及新增租户是否需要昂贵改造。

#### 5.2.2 MNO 的实际选择不是“自建或外包”二选一

常见组合至少包括：

- **保留核心站点，自有自营。** 对战略位置、核心机房或特殊网络保持控制。
- **把被动资产卖给独立 TowerCo 并回租。** 获得一次性资金，形成长期锚定合同。
- **与其他 MNO 组建共享网络或 TowerCo 合资公司。** 共享成本，同时保留一定治理权。
- **在第三方现有站点共址。** 不新建塔，只安装主动设备，是最直接的需求来源。
- **委托 BTS。** 在 Cellnex 没有存量站址的位置，由其按需求新建。
- **仅采购工程、DAS、光纤或运维。** 资产边界因国家和项目而异。

MNO 会对每个位置比较网络质量、时间、总成本、合同灵活性和替代供给，而不是在全国范围只做一次永久选择。即使已经把大部分塔卖给 Cellnex，也可能继续自建特殊站、参与 RAN sharing，或在续约时把部分设备迁往竞争站点。

#### 5.2.3 从网络缺口到 TowerCo 订单的决策流程

```text
网络监控发现覆盖/容量/SLA 缺口
  -> 无线规划确定目标区域（search ring）、频段、天线高度和容量
  -> 先判断能否通过软件、频谱或现有设备升级解决
      -> 能：可能只有工程/amendment，未必新增 PoP
      -> 不能：寻找现有合格站址
          -> Cellnex 有合适站：技术勘察、报价、共址或改造
          -> 没有合适站：比较 Cellnex BTS、MNO 自建、其他 TowerCo 或网络共享
  -> 商业采购：价格、期限、调价、SLA、CapEx 责任、退出和去站条款
  -> 许可/施工/安装/验收
  -> 开站并开始经常性收费
```

**需求漏斗。** 从“用户流量增长”到“Cellnex 收入”之间至少经过技术可替代性、站址可用性、采购选择、合同谈判和工程交付五道筛选。研究时必须逐层判断，不能把欧洲 5G 用户增长率直接当作 Cellnex 收入增速。

### 5.3 无线网络为什么需要不同类型的站点

移动网络要同时解决覆盖、容量、室内穿透、移动连续性和可靠性。这些目标并不总能由同一种宏塔解决。

#### 5.3.1 频段决定“传得远”还是“装得多”

| 频谱类型 | 一般物理特征 | 主要用途 | 对站点需求的典型影响 |
|---|---|---|---|
| 低频段 | 传播较远、绕射和室内穿透较好，但可用带宽通常较有限 | 农村、广覆盖、基础室内覆盖 | 单站覆盖面积较大，适合高塔；站点数量需求相对较低但位置关键 |
| 中频段，如 3.4-3.8 GHz | 容量和覆盖折中，5G 容量层的重要频段 | 城市、郊区、高容量移动宽带和 FWA | 常需要更密集的站点、更多设备和更强回传 |
| 更高频段 | 可提供更大带宽，但传播和穿透更受限制 | 热点、场馆、街区和特殊高容量场景 | 更依赖 Small Cells、DAS、街道设施和精细化部署 |

这里不是说频率每提高一次就必然新建一座塔。运营商可以把新频段加到现有站点，也可以通过 Massive MIMO、波束赋形、扇区化或软件优化提高能力；只有现有站点无法满足目标时，才需要新增物理密度。

#### 5.3.2 覆盖、容量和质量是三种不同需求

| 网络问题 | 用户感受 | MNO 常见解法 | Cellnex 的对应产品 |
|---|---|---|---|
| 没有覆盖 | 无信号、道路或乡村断点 | 新宏站、低频补网、共享站点 | 存量共址、BTS、高塔、特殊站址 |
| 有信号但容量不足 | 高峰变慢、视频卡顿、FWA 拥塞 | 加频谱/设备、扇区、小区分裂、Small Cell | amendment、站点加固、新 PoP、BTS、Small Cells |
| 室内或地下穿透差 | 建筑、地铁、机场内无稳定服务 | DAS、室内 Small Cells、专用光纤 | 中立多运营商 DAS、Small Cells、FTTT/回传 |
| 移动连续性差 | 铁路、公路、隧道中频繁掉线 | 走廊连续站点、隧道系统和切换优化 | 交通基础设施覆盖、DAS、光纤、工程运维 |
| 可靠性不足 | 停电或灾害时中断 | 电池、发电、双回传、NOC 和快速维修 | Energy resilience、Mission Critical、SLA、O&M |
| 企业/政府需要专用网络 | 公网无法满足安全、时延或控制要求 | 私网、RANaaS、PPDR/TETRA/5G | RANaaS、Mission Critical、专线和 Housing |

#### 5.3.3 宏站、屋顶、Small Cell 和 DAS 的分工

**宏站/高塔**覆盖范围较大，适合形成连续网络骨架；**城市屋顶站**利用建筑高度服务密集城区，但受物业租约、承载和城市规划限制；**Small Cell**功率较低、覆盖小，适合填补局部容量和盲点；**DAS**把多个室内天线连接到共同信号源，适合机场、体育馆、医院和隧道，并可设计为多运营商共享。[S06][S07]

这些资产不是简单替代关系，而是分层组合。宏站可以让街区“有信号”，但未必能穿透大型建筑；DAS 能解决建筑内部，却不能替代城市范围的连续覆盖；Small Cell 能提供热点容量，但数量多、场地碎片化、供电和回传要求高。Cellnex 将这些产品放在同一平台上，目的是让客户从“找一个塔”转向“采购一个地点或场景的完整连接条件”。

### 5.4 需求侧之一：覆盖需求

覆盖需求解决的是“某个区域有没有连续可用的信号”，主要来自农村、交通走廊、隧道、地下空间、新开发区、边境和公共安全网络。MNO 的频谱牌照或公共政策可能附带人口、地理或交通覆盖义务；偏远地区的商业回报较弱，因此还可能依赖政府项目、共享建设或长期锚定合同。

不同频段对站址的要求不同。低频频谱传播距离长、穿透能力较强，适合广覆盖；3.4-3.8 GHz 等中频频谱能够提供更大容量，但覆盖半径和室内穿透通常弱于低频，往往需要更多站点、设备升级或室内补点。欧盟委员会披露，截至 2025 年中，欧盟家庭的一般 5G 信号覆盖率已达 96.8%，但 3.4-3.8 GHz 5G 覆盖率仅 74.8%；FWA 在低密度和地理困难区域的重要性也在上升。[S28]

由此需要区分两件事：

- **广义覆盖已较成熟。** 欧洲总体 5G 覆盖接近普及，单纯依赖“从无到有”的全国宏站铺设，长期增量空间不应被高估。
- **容量型覆盖仍有缺口。** 中频覆盖低约 22 个百分点，说明“看得见 5G 图标”与“拥有足够容量的 5G 网络”不是一回事；中频补网、室内覆盖和局部密集化仍可能带来共址、BTS、DAS 和 FTTT 需求。[S28]

对 Cellnex 而言，覆盖需求通常通过三种形式变现：第一，客户进入已有站点形成共址；第二，在没有合适存量站址时签长期锚定合同，由 Cellnex BTS；第三，在机场、地铁、隧道、医院和大型建筑中建设 DAS/Small Cells。Grand Paris Express、米兰机场和 Tour Alto 等案例证明了交付形态，但并不证明每个项目具有相同利润率或可复制性。[S17][S18][S20]

### 5.5 需求侧之二：容量、密集化和 5G 升级

容量需求解决的是“已有信号是否能承载高峰流量”。简化地看，一张网络的容量来自可用频谱、频谱效率、扇区/天线配置和可复用信号的小区数量。MNO 面对流量增长时通常依次或组合采取：优化软件和频谱、升级主动设备、增加天线/扇区、在已有站点增加设备、建设新宏站、部署 Small Cells/DAS，以及增强回传。

可以用一个非会计、非工程精算的关系帮助理解：

```text
某一区域可承载的无线容量
  ≈ 可重复使用信号的小区数量
  × 每个小区可用频谱带宽
  × 频谱效率
  × 扇区、天线配置和实际网络利用因素
```

MNO 获得更多频谱或换用更高效的主动设备，可以在不新增站点的情况下提高容量；把一个大覆盖小区分成多个更小小区，则需要更多物理位置，最容易形成宏站、屋顶站或 Small Cell 需求。即使无线容量提高，如果回传不足，用户仍会拥塞，因此中频和热点扩容还可能带动 FTTT、传输和供电升级。

Ericsson 预计全球移动数据流量从 2025 年的约 146 EB/月增长至 2031 年的 328 EB/月，约为 2.2 倍；西欧每部活跃智能手机的月均流量预计从 25GB 增至 59GB，复合增速约 15%。但该报告也明确警告，区域月均流量不能用于直接估算某一本地地区的日高峰或网络演进：密集城市位置的需求最高可达到农村位置的约 1,000 倍。[S29]

这意味着 Cellnex 的需求应按“具体地点”而不是按欧洲总流量判断：

| 上游触发因素 | MNO 的物理网络动作 | Cellnex 可能获得的业务 | 收入质量与局限 |
|---|---|---|---|
| 存量区域流量增长但仍有设备余量 | 软件优化、频谱重耕、天线/射频升级 | 工程或 amendment，未必新增 PoP | 资本需求较小，但收入可能一次性或增量有限 |
| 已有站点需要更多设备或另一频段 | 增加天线、机柜、重量、功率和回传 | 站点改造、承载加固、额外占用费、FTTT | 可利用存量站点，但并非零 CapEx |
| 局部容量逼近上限 | 小区分裂、新宏站、屋顶站或 Small Cell | 共址、BTS、Small Cells | 最能转化为持续收入，但受许可与选址约束 |
| 室内流量高、宏站穿透不足 | 多运营商 DAS 或室内 Small Cells | DAS 设计、建设、运营及 SLA | 客户可能包括 MNO 与物业方，合同和回报异质性较高 |
| FWA 用户增长 | 宏站容量、天线和回传扩容 | 站点升级、新 PoP、BTS、光纤 | 既可能扩大站点需求，也可能挤占移动用户容量 |

GSMA 预计欧洲 5G 连接占比到 2030 年达到 88%，并强调长期投资条件对网络建设的重要性；这是运营商行业组织的预测与政策主张，应作为行业预期而非独立监管事实使用。[S30]

**分析判断。** 对 Cellnex 最有价值的不是流量本身，而是“流量的空间不均衡性 + 中频网络更密集 + 现有优质站点可复用”。当新增容量能够在既有站点通过共址或设备扩容完成时，Cellnex 的增量回报通常最好；当必须新建单租户 BTS 时，收入更确定但前期资本强度更高，最终回报依赖第二、第三租户能否进入。

### 5.6 需求侧之三：质量、韧性和资本配置

除覆盖和容量外，客户还需要网络连续性、低时延、室内可用性和灾害/断电韧性。医院、铁路、机场、警务和应急网络不能只追求平均下载速度，还需要明确 SLA、备用电源、冗余传输、24x7 NOC 和现场维护。这些要求支持 Cellnex 的电池与备用能源、Mission Critical、RANaaS、Fiber 和运维业务。[S01][S11][S13]

TowerCo 需求还来自 MNO 的资本配置，而不只是无线技术：

1. MNO 可以出售被动资产或把自建 CapEx 转为长期服务费，释放资本投入频谱、主动 RAN、核心网、IT 和客户竞争。
2. 中立宿主可以让相互竞争的 MNO 共用土地、塔桅、供电和维护，减少重复建设。
3. 专业 TowerCo 集中处理选址、地主、许可、结构工程和运维，有机会缩短部署周期。
4. 跨国 MSA/BTS 计划可把不连续的单站需求变成可规划的长期建设量。

但“表外/轻资产”并不等于客户总成本一定更低。MNO 用资产出售的一次性现金，换取了长期、带调价条款的服务承诺；当 TowerCo 供给集中或合同退出成本高时，客户可能失去部分议价权。英国 CMA 对 Cellnex 收购 CK Hutchison 英国被动资产的审查就认为，交易会阻止一个重要替代供应商出现，可能让 MNO 面临更高价格和更苛刻条款，因此要求出售超过 1,000 个地理重叠站址。[S31]

### 5.7 按客户、场景和业务线理解需求

Cellnex 并非只有一种客户，也不是所有需求都由移动流量驱动。Towers 高度依赖 MNO；DAS、Small Cells、Fiber、Mission Critical 和 Broadcast 的购买者、预算来源、合同结构与周期并不相同。

#### 5.7.1 谁在购买，为什么购买

| 付费客户/决策者 | 直接问题 | 采购决策通常由什么触发 | Cellnex 交付 | 需求特征 |
|---|---|---|---|---|
| 成熟大型 MNO | 存量网络扩容、5G、中频补网、成本优化 | 容量 KPI、频谱部署、设备换代、网络整合 | 共址、amendment、BTS、工程、FTTT | 规模大但议价强，可能同时带来增长和 churn |
| 新进入者/挑战者 MNO | 快速建立全国或区域覆盖 | 获得频谱、推出商业服务、监管覆盖义务 | 大规模共址和选择性 BTS | 时间敏感，对已有全国站址组合价值较高 |
| MNO 网络共享主体 | 合并两家网络资源并降低重复成本 | RAN sharing、合资网络、MNO 并购 | 保留站点扩容、迁移、去站和共享 | 一部分站点需求集中，一部分重复 PoP 消失 |
| 政府/公共安全机构 | 高可靠、加密、群组通信和灾害韧性 | 公共采购、网络现代化、应急要求 | TETRA/LTE/5G PPDR、Mission Critical、运维 | 项目与合同周期长，合规和 SLA 要求高 |
| 地铁、铁路、机场运营方 | 隧道、车站和交通走廊连续连接 | 新线路建设、客流数字化、安全系统升级 | DAS、Small Cells、光纤、关键通信 | 工程复杂，受建设窗口和多方协调影响 |
| 场馆、医院、酒店、办公和商业地产 | 宏网无法提供稳定室内容量 | 用户投诉、租户体验、数字化运营、物业升级 | 多运营商 DAS、Small Cells、私网和运维 | 需要协调物业与多家 MNO；利用率有场景差异 |
| 其他运营商/宽带商 | 回传、专线、机房和接入位置 | 网络扩张、冗余和边缘部署 | Fiber、Connectivity、Housing、站址 | 与本地光纤可达性及批发竞争相关 |
| 广播机构 | 全国或区域电视、广播信号分发 | 牌照、公共服务和合同续约 | DTT、广播、DAB+、NOC 和媒体连接 | 成熟、区域性强，更多由续约和技术迁移驱动 |

#### 5.7.2 四条业务线各自依赖什么需求

| 业务线 | 第一需求变量 | 第二需求变量 | 主要正向驱动 | 主要反向驱动 |
|---|---|---|---|---|
| Towers | MNO 的站点占用与设备量 | 自建/共享/外包选择 | 中频部署、热点密集化、新进入者、存量共址 | MNO 合并、RAN sharing、去站、设备效率提升 |
| DAS/Small Cells/RANaaS | 室内/密集区覆盖和主动网络服务需求 | 物业、交通和政府项目预算 | 大型建筑数字化、交通建设、公共安全和私网 | 项目延期、多方付费意愿不足、宏网改善替代 |
| Fiber/Connectivity/Housing | 无线站点和企业的回传/传输需求 | 本地光纤覆盖与批发价格 | 5G 回传、FWA、冗余、边缘连接 | 光纤重叠建设、价格竞争、资产处置 |
| Broadcast | 电视和广播分发合同 | 牌照与公共服务安排 | 合同续约、DAB+、网络运维 | 传统广播成熟、OTT 替代、监管和客户集中 |

**不能把四条线放进同一增长公式。** Towers 的核心指标是 PoP、共址、churn 和 tenancy；DAS 是项目节点、签约场所和多运营商参与；Fiber 更接近路线、连接和批发容量；Broadcast 则看牌照、覆盖义务和续约。即使四条线都被称为“数字基础设施”，需求周期、资本强度和利润率也不同。[S01][S24]

#### 5.7.3 同一种流量增长，可能产生完全不同的 Cellnex 结果

| 现实情况 | MNO 的选择 | Cellnex 的结果 |
|---|---|---|
| 流量增长但现有频谱和设备仍有余量 | 软件优化或负载均衡 | 基本没有新增收入 |
| 新增中频设备可直接放上现有站点 | 原租户增加设备 | amendment、工程费或额外占用费，未必增加新客户 |
| 竞争 MNO 进入 Cellnex 现有站点 | 共址 | 新增经常性 PoP，固定成本复用较高 |
| 现有站点承载不足 | 先加固再部署 | 收入增长同时产生 Tower Expansion CapEx |
| 搜索区域没有可用站 | 委托 BTS | 未来长期收入增加，但先发生建设现金流出 |
| 室内流量无法由室外宏站解决 | DAS/Small Cell | 项目收入和长期运维，资本/合同结构与 Towers 不同 |
| MNO 通过 RAN sharing 合并设备 | 迁移并去除重复 PoP | 少数保留站可能扩容，但组合净 churn 可能为负 |

这张表是需求分析的核心：**技术需求、设备需求、站点需求和 Cellnex 收入需求是四个不同层级。** 研究必须确认增长最终落在哪一级。

### 5.8 什么会削弱或摧毁需求

| 需求抵消因素 | 作用机制 | 对 Cellnex 的可能影响 | 观察重点 |
|---|---|---|---|
| MNO 合并 | 两张网络重叠，合并后去除重复设备和站点 | churn 上升；续约数量和价格承压 | 国家级并购、合同去站保护、迁移至 Cellnex 其他站点的比例 |
| RAN sharing / 网络共享 | 两家运营商共享主动或被动网络 | 减少总 PoP，也可能把流量集中到质量更高的共享站点 | 共享范围、保留站点清单、是否由 Cellnex 承载 |
| 频谱增加与频谱效率提升 | 同一站点承载更多容量 | 延迟新站建设；可能仍产生设备改造和承载升级 | 频谱拍卖、设备代际、站点 amendment 收入 |
| 网络合理化 | MNO 主动拆除低利用率或重复站点 | 直接形成 churn | Gross PoP 与 Net PoP 之差、decommissioning 费用 |
| MNO 回报偏低或 CapEx 收缩 | 延后 5G、BTS 和室分项目 | 订单和交付放缓，客户议价增强 | 主要客户 CapEx、自由现金流、信用评级 |
| 卫星直连终端 | 为偏远地区提供基础覆盖替代 | 可能减少极偏远地区宏站需求，但难替代城市容量和深度室内覆盖 | D2D 商用频段、终端普及、实际容量与资费 |
| 长约重谈和客户集中 | 少数大客户利用规模压价或改变条款 | escalator、最低承诺和续约价值下降 | 前三/前五客户占比、续约窗口、合同 cap/floor |

公司把 MNO 合并、RAN sharing、去站和技术替代列为风险；2024 CMD 又披露前三大客户约占收入 48%。因此长期 MSA 可以平滑需求，但不能消灭需求：合同期内的保护取决于最低承诺、退出条款和去站补偿，合同到期后仍要面对网络结构变化。[S01][S03]

### 5.9 供给侧：TowerCo 真正供应的是什么

“塔站供给”不是一个单一数量。对客户而言，可用供给至少分五层：

| 供给层级 | 交付内容 | 供给速度/资本强度 | 主要瓶颈 |
|---|---|---|---|
| 存量站点共址 | 在现有塔桅、屋顶或场地增加客户 PoP | 通常最快、资本效率最高 | 剩余空间、结构载荷、频率干扰、供电和合同权限 |
| 存量站点扩容改造 | 加固塔体、扩建地面机房、升级电力/电池/光纤 | 中等速度和 CapEx | 工程设计、停机协调、许可变更和供应链 |
| 新建宏站/BTS | 新选址并建设塔桅、机房、供电和回传 | 最慢、前期资本强度高 | 选址、地主、规划许可、社区、并网和锚定客户 |
| DAS/Small Cell/室内系统 | 在建筑、交通或场馆内布置多节点覆盖 | 项目制，复杂度差异大 | 物业权利、室内布线、消防/施工、多个 MNO 协调 |
| 光纤、回传、Housing 与韧性 | 连接站点并提供传输、机柜、电力、冗余和运维 | 取决于既有网络可达性 | 路权、土建、上游光纤/电网、能源和 SLA |

**核心结论。** 稀缺的不是钢材或塔桅制造能力，而是一个“位置正确、权利稳定、许可有效、结构够强、有电、有回传、可维护且能让多家客户共同使用”的站点。钢塔可以异地生产，但网络覆盖位置不可搬移；相距几公里的两个站点，在射频覆盖、许可、地主合同和客户价值上可能完全不可替代。

### 5.10 一座新站或一次共址如何真正成为供给

从客户提出网络缺口到 Cellnex 开始收费，并不是“买一座铁塔并立起来”。每个站点要经过位置、权利、许可、工程、商业和验收的连续流程，其中任一环节失败，名义供给都不能变成可用供给。

#### 5.10.1 新建 BTS 的完整生命周期

| 阶段 | 主要工作 | 关键参与方 | 失败或延期原因 | 对财务的影响 |
|---|---|---|---|---|
| 1. 无线规划 | MNO 确定覆盖缺口、search ring、频段、高度和容量 | MNO 无线规划团队 | 技术方案变化、预算取消 | 尚未形成 Cellnex 收入 |
| 2. 商业意向 | 确定由 Cellnex BTS，并谈站点规格、数量和时限 | MNO 采购、Cellnex 商务 | 回报、价格、期限或责任无法达成 | 可能进入建设承诺，但未必立即确认收入 |
| 3. 选址 | 在目标区域寻找土地、屋顶或特殊结构 | Cellnex、地产代理、地主 | 无合适高度/位置、业主拒绝、进入条件差 | 发生开发成本和时间成本 |
| 4. 土地权利 | 签租约、购买权利或取得长期使用安排 | Cellnex、地主、律师 | 产权不清、租金过高、转租受限、租期不足 | 形成长期租金或预付现金承诺 |
| 5. 技术勘察 | 地质、结构、风载、电磁、道路、电力和回传评估 | 工程师、电网、光纤商、MNO | 地基/承载不足、并网困难、回传不可达 | 可能重选址或增加预算 |
| 6. 规划与许可 | 申请规划、建筑、环境、航空和地方许可 | 地方政府、监管方、社区 | 审批延期、公众反对、附加条件 | 推迟 CapEx 和收入起点，可能产生沉没成本 |
| 7. 设计采购 | 确定塔型、基础、机房、电池和施工方 | Cellnex、设备/施工供应商 | 材料涨价、交期、设计变更 | 锁定项目成本和供应链风险 |
| 8. 施工并网 | 建基础、立塔、围栏、供电和回传接入 | 承包商、电网、光纤商 | 天气、安全事故、施工窗口、并网延期 | 发生 BTS CapEx 和现金流出 |
| 9. 客户安装 | MNO 安装天线、射频、基带和传输设备 | MNO、设备商、Cellnex | 设备交付、配置、站点协调 | Cellnex 已建成但可能尚未开始完整收费 |
| 10. 测试验收 | 验证覆盖、容量、安全、文件和 SLA | MNO 与 Cellnex | 性能不达标、整改、文档不完整 | 验收后通常开始或稳定确认经常性收入 |
| 11. 运营维护 | NOC、现场维修、能源、合规和地主关系 | Cellnex、供应商、地主 | 故障、停电、租约争议、法规更新 | 形成服务收入及地租、维护、能源成本 |
| 12. 共址扩容 | 寻找第二客户、进行结构/电力适配 | Cellnex、新 MNO | 无第二客户需求、承载不足、价格不合适 | 新增 PoP；可能先发生 Expansion CapEx |
| 13. 续约/退网 | 延长 MSA 和租约，或拆除并恢复场地 | MNO、Cellnex、地主 | MNO 合并、站点重复、租金大涨 | 续约保持现金流；退网形成 churn 和拆除成本 |

这个流程揭示了 BTS 的两个时间差。第一，CapEx 通常先于收入发生，许可和验收延期会延长负现金流期；第二，第二、第三租户通常晚于锚定客户，站点的成熟回报可能多年后才显现。公司未披露完整的平均开发周期、失败率和各年份共址曲线，因此不能从签约 BTS 数量直接推算短期 FCF。

#### 5.10.2 存量共址也不是“把设备直接挂上去”

现有站点共址省去了重新取得整个站址的过程，但仍需完成：

1. 确认站点在客户 search ring 内且高度、方位满足无线规划。
2. 检查 MSA 和地主合同是否允许新增租户、设备和进入施工。
3. 进行结构分析，评估天线重量、风载、支架和塔体余量。
4. 检查机柜、地面空间、电力、制冷和线缆路径。
5. 判断是否需要规划许可变更、电磁申报或业主批准。
6. 形成报价，约定经常性占用费、工程费、CapEx 责任和交付 SLA。
7. 加固或适配后安装、测试和验收。

因此，共址的边际利润通常高于新建站，但不是 100% 毛利。若老塔需要大规模加固、扩电或更换结构，新增收入可能伴随显著 Tower Expansion CapEx；真正优质的供给是“客户正好需要且无需重大改造的剩余容量”。

#### 5.10.3 DAS 和交通项目为什么更复杂

DAS/Small Cell 项目通常没有一座独立塔，而是在建筑或隧道内铺设大量节点、线缆、电源和设备空间。付费方可能是物业、交通业主、MNO 或多方组合；还要协调消防、装修、施工时段、公共安全、多个 MNO 的信号源和后续升级。项目节点多不等于收入或回报一定高，必须看谁支付初始建设、最低服务费、运营期限和未来技术升级责任。[S07][S17][S18][S20]

### 5.11 供给约束一：位置、权利、许可和工程条件

**位置和土地/屋顶权利。** 站址必须落在无线规划需要的搜索环内。Cellnex 多数站点依赖第三方土地、屋顶租约或其他使用安排，因此租约期限、续租价格、转租权、进入权和业主信用会决定供给能否持续。买地、预付、延长租期和重新议价，本质上是在提高站址权利的稳定性并降低未来 lease cash-out。[S01][S16]

**规划和许可。** 新站或重大改造可能涉及规划、建筑、历史保护、航空、环境、电磁和社区程序。欧盟《Gigabit Infrastructure Act》自 2025 年 11 月 12 日起一般适用，目标是降低光纤和 5G 部署成本与复杂性，包括促进基础设施共享、协调土建、与公共工程同步建设、数字化许可流程，以及开放既有基础设施和计划工程信息。[S27] 这可能提升供给弹性，但实际效果仍取决于各成员国和地方机关执行，不应假设欧洲许可周期已经统一消失。

**结构、空间和安全。** 新设备会增加重量、风载、线缆和地面机柜占用；一座“有空位”的塔也可能因承载不足而不可共址。加固工程需要结构计算、供应链、现场施工和客户停机协调。DAS/Small Cell 项目还受建筑消防、装修、隧道施工窗口和物业审批约束。

**供电和回传。** 没有足够电力、备用电源和光纤/微波回传，物理塔桅不能形成可用网络容量。电网接入、能源价格、光纤路权、设备交期和冗余标准都会影响投产时间；对于 Mission Critical 和高 SLA 项目，电池、发电、双路由和持续监控还是产品的一部分。

### 5.12 供给约束二：合同、资本和组织能力

**锚定客户使新供给可融资。** BTS 通常要先有 MNO 的长期承诺，才能覆盖选址和建设风险。没有锚定客户的新塔类似投机开发：即便未来可能共址，也缺少初始现金流。反过来，过于依赖单一锚定客户会提高信用和续约风险。

**资本成本决定项目是否跨过回报门槛。** TowerCo 资产久期长、前期 CapEx 大，债务成本、信用评级、可用授信和股东回报要求都会影响新增供给。Cellnex 净金融债务约 EUR 20.8bn，并把投资级评级和项目级回报作为当前资本配置约束；利率或信用利差上升时，即使工程上可以建设，部分低密度 BTS 和室分项目也可能因回报不足而不再供应。[S01][S02][S03]

**长期合同既稳定供给，也冻结供给。** MSA/MLA 和地主租约让客户和 TowerCo 敢于投资，但也会形成排他、优先权、定价公式和迁移限制。存量站点名义上存在，不代表任何 MNO 都能以合理条款立即使用；需要核对合同是否允许多租户、剩余容量和升级责任。

**组织能力影响交付速度。** 供给还依赖选址、规划、结构工程、采购、施工、安全、NOC、维护和地主管理团队。Cellnex 的跨国平台能复用流程、采购和监控系统，但许可、地主和无线规划仍高度本地化，不能完全依靠总部规模标准化。

### 5.13 存量供给、新增供给与供给弹性

分析 TowerCo 供给时必须区分“全行业已经存在的站点存量”和“某家公司拥有的站点组合”。Cellnex 收购一组 MNO 塔站，会扩大 Cellnex 的公司供给和收入，却没有在当日增加社会上的物理塔数；真正增加行业物理供给的是 BTS、新屋顶站、Small Cells、DAS、光纤和既有站点扩容。

#### 5.13.1 四种不同的供给变化

| 变化类型 | 行业物理供给 | Cellnex 可销售供给 | 对收入/资本的典型影响 |
|---|---|---|---|
| 收购已有塔站组合 | 基本不变，只改变所有权 | 大幅增加 | 支付 M&A 对价，获得存量锚定收入和共址选择权 |
| 在已有站点增加可用容量 | 增加有效供给 | 增加 | Expansion CapEx 后可容纳更多设备/租户 |
| 新建 BTS | 新增物理站点 | 增加 | 前期建设 CapEx，随后形成锚定收入和未来共址池 |
| 出售或监管剥离站点 | 行业物理供给基本不变 | Cellnex 减少、买方增加 | Cellnex 收到处置款并失去对应未来现金流 |
| 去站/拆除 | 减少物理供给 | 减少 | churn、拆除成本；可能把客户迁往剩余优质站点 |
| 开放公共杆件/屋顶/交通设施 | 增加候选位置 | 取决于 Cellnex 是否获得经营权 | 有利于 Small Cell 和城市密集化，竞争也可能加剧 |

这一区分对理解 Cellnex 的历史尤其重要。2015-2022 年公司的高速增长很大部分来自收购和整合现有资产，是公司份额扩张；当前更强调共址和选择性 BTS，才更直接反映存量资产利用与新物理供给。[S03][S24]

#### 5.13.2 供给在不同时间尺度上的弹性

| 时间尺度 | 可采取的动作 | 供给弹性 | 为什么 |
|---|---|---|---|
| 很短期 | 利用已有空位和现成电力完成简单共址 | 相对最高，但仅限合格站点 | 位置、合同和结构均已存在，主要是勘察与安装 |
| 短中期 | 加固塔体、扩电、增加机柜和光纤 | 中等 | 需要工程、许可变更、供应链和客户协调 |
| 中长期 | 新建宏站/BTS、取得新屋顶或公共设施 | 较低且高度本地化 | 需要选址、地主、规划、社区、并网和锚定合同 |
| 长期 | 建立新地区平台、批量 BTS 或收购整合 | 公司层面可显著扩大 | 需要大量资本、组织能力和监管批准；收购未必增加行业总供给 |

**价格不能让供给立即出现。** 即使 MNO 愿意支付更高费用，某个城市搜索环内也可能没有合法屋顶、结构余量或电网接入；价格只能提高地主和投资者的参与意愿，不能瞬间消除规划和物理限制。这使站址供给比一般标准化设备更缺乏弹性。

#### 5.13.3 什么因素会真正扩大有效供给

- 地方许可数字化、审批期限缩短以及规划规则清晰化。
- 允许共享公共管道、建筑物、路灯杆、交通设施和既有土建信息。
- 更容易取得长期土地/屋顶权利和进入施工权。
- 塔体标准化、结构加固、数字孪生和更准确的容量数据库。
- 电网并接、电池和光纤/微波回传可得性提高。
- 有信用的锚定客户和足以覆盖资本成本的长期合同。
- 施工、工程、维护人才及供应链能力增加。
- TowerCo 有足够债务/权益资本，同时没有突破评级和杠杆约束。

欧盟《Gigabit Infrastructure Act》针对基础设施共享、土建协调、许可数字化和既有设施信息的改革方向，理论上正作用于上述部分瓶颈；但它扩大的是“更容易部署的制度条件”，不是自动为 Cellnex 创造独占供给。竞争 TowerCo 和 MNO 自建也会受益。[S27]

### 5.14 竞争供给、替代品和监管边界

Cellnex 的直接竞争供给包括其他独立 TowerCo、MNO 自有站点、MNO 网络共享合资公司、专业室分/光纤运营商，以及可出租屋顶、公共路灯杆和交通基础设施的业主。间接替代包括运营商用更多频谱和主动设备提高单站容量，或在偏远地区使用 FWA、卫星和其他接入技术。

供给竞争具有明显的地方性：一家 TowerCo 在欧洲站点很多，并不意味着它在某个特定搜索环内有替代站点。英国 CMA 要求 Cellnex 出售超过 1,000 个地理重叠站点，恰好说明监管关注的不是全欧洲抽象“塔数”，而是 MNO 在未来合同谈判中是否存在可用的被动基础设施替代供应商。[S31]

因此，高进入壁垒不等于无限定价权：

- MNO 可以自建、共享或把设备迁到其他站点，虽然迁移有成本。
- 长约调价通常受 CPI cap、固定 escalator 或谈判条款约束，现货稀缺不会立刻全部转为价格。
- 竞争机关可以阻止并购或要求资产剥离，以维持替代供给。
- 站址过于昂贵时，MNO 会重新优化射频规划，减少占用空间或延迟建设。

### 5.15 需求与供给如何共同决定 Cellnex 的基本面

| 情景 | 需求侧 | 供给侧 | 对 Cellnex 的主要含义 |
|---|---|---|---|
| 流量高增长、中频继续部署、许可改善 | 共址、改造、Small Cell 和 BTS 增加 | 存量扩容和新站交付加快 | Organic growth 与 PoP 上升；需观察 CapEx 是否同步失控 |
| 流量高增长但新站许可严格 | 客户容量缺口扩大 | 新供给慢，优质存量站点稀缺 | 存量站点价值和共址需求增强，但交付延期、加固成本也上升 |
| 5G 覆盖成熟、流量由设备升级吸收 | 新宏站需求放缓 | 存量供给充足 | 塔数增长弱，收入更多来自 escalator、amendment 和运维提效 |
| MNO 合并与 RAN sharing 加速 | 重复 PoP 和站点被去除 | 市场剩余客户更集中 | churn、续约和议价压力增加；部分迁移可能集中到 Cellnex 优质站点 |
| 利率和信用利差长期高位 | MNO 与 TowerCo 都压缩投资 | 新 BTS/室分供给因回报门槛收缩 | FCF 短期可能因少投资改善，但中长期增长管线变弱 |
| 卫星 D2D 在偏远地区规模商用 | 最偏远覆盖需求部分被替代 | 城市容量、室内和关键通信仍需地面网络 | 农村边际站点承压，核心城市/交通站点影响较小 |

**分析判断一：Cellnex 的核心资产是局部供给选择权。** 一个尚有结构、电力和空间余量的优质存量站点，能够以较低增量资本吸收第二、第三租户；这比“站点总数”更能解释未来回报。tenancy ratio 上升只有在不是由低质量站点处置或统计口径变化驱动时，才真正代表复用效率改善。

**分析判断二：需求增长与 FCF 可能短期反向。** BTS 旺盛时，未来合同收入和站址选择权增加，但当期 CapEx 上升、FCF 受压；削减 BTS 会立即改善 FCF，却可能减少后续共址池。因此不能把 FCF 上升自动解释为长期供需地位增强，要同时看 gross co-location、BTS 交付、项目回报和未来共址率。

**分析判断三：最理想的组合是“存量稀缺 + 多客户需求 + 可控改造 CapEx”。** 这会形成较强的增量利润和现金转换。最差的组合是“偏远单租户 BTS + 昂贵地主租约 + 低共址潜力 + 高融资成本”，即使合同期限很长，也可能只获得普通甚至不足的资本回报。

### 5.16 建议持续跟踪的供需指标

| 类别 | 指标 | 需要回答的问题 |
|---|---|---|
| 上游需求 | 各国移动数据流量、峰值/热点分布、3.4-3.8 GHz 覆盖、FWA 连接 | 流量发生在哪里，是否需要站点密集化而非仅设备升级？ |
| MNO 投资 | 主要客户 CapEx、频谱投入、网络共享、并购和去站计划 | MNO 是否有能力和意愿把技术需求转成订单？ |
| 需求转化 | Gross PoP、Net PoP、共址/BTS/其他项目拆分、churn | 上游需求有多少真正成为 Cellnex 的收费点？ |
| 资产复用 | Tenancy ratio、每站收入、存量改造量和 CapEx | 新租户是否复用固定成本，还是需要大量加固？ |
| 新供给 | BTS 交付、在建量、平均许可/建设周期、每站 CapEx | Cellnex 能否按时、按预算扩大网络？ |
| 站址权利 | 地租现金支出、续租成功率、剩余租期、买地/预付比例 | 稀缺站址的经济权益是否稳定，成本是否跑赢客户调价？ |
| 资本供给 | 项目 IRR、净债务/EBITDA、债务成本、评级和流动性 | 技术上可建的项目，在资本上是否仍值得建？ |
| 竞争与监管 | 各国 TowerCo 份额、替代站址、许可改革和并购救济 | 高壁垒是否转化为回报，还是触发监管和客户反制？ |
| 最终经济性 | Organic growth、EBITDAaL margin、RLFCF、FCF | 增长来自定价、共址还是高资本强度 BTS，现金质量如何？ |

### 5.17 尚未解决、需要进入国家与客户层面的问题

1. Cellnex 十个经营国家各自的 3.4-3.8 GHz 覆盖、频谱部署、MNO CapEx 和站点密度差异有多大？欧洲平均数不能替代国家和城市级判断。
2. 各主 MSA 中共址、设备扩容、去站、最低承诺和 renewal pricing 的具体条款是什么？长期合同名义期限不足以判断真实需求保护。
3. 现有站点中有多少无需重大加固即可增加第二或第三租户？公开 tenancy ratio 没有给出剩余结构、电力和地面空间分布。
4. BTS 项目从签约到许可、建设、验收的平均周期和成本超支率是多少？公司没有完整公开国家级数据。
5. 新 BTS 在第 3、5、10 年获得第二租户的比例和项目级税后无杠杆 IRR 是多少？这是判断“增长”能否转为价值的关键缺口。
6. MNO 合并、RAN sharing 与站点迁移中，有多少 churn 会流向 Cellnex 组合内的另一个站点，而不是彻底流失？
7. DAS、Fiber、RANaaS、PPDR 和韧性项目的合同久期、独立 EBITDAaL、维护资本和客户集中度如何？这些相邻业务不能直接套用核心 Towers 的供需和估值逻辑。
8. 各国站点组合中，城市、郊区、农村、屋顶、高塔和特殊站址分别占多少，其共址率和地租负担有何差异？
9. Organic growth 中基础调价、共址、amendment、BTS、工程和一次性项目分别贡献多少？公司当前披露不足以完整拆分。
10. 主要客户的站点租用成本占其网络 Opex/CapEx 的比例如何，什么价格水平会促使其自建、共享或迁移？

**本章结论。** 对 Cellnex 的需求来自三层叠加：终端流量与覆盖要求提供技术需求，MNO 的自建/共享/外包选择把技术需求变成商业需求，具体站点的许可、结构、电力和回传条件决定需求能否成交。其供给优势也不是“拥有很多钢塔”，而是把分散的本地权利和工程能力组织成可供多家客户长期使用的站址网络。未来最值得关注的不是欧洲流量是否增长，而是增长是否发生在 Cellnex 有优质可扩容站点的区域、是否转化为高回报共址，以及新 BTS 的资本回报能否覆盖长期融资和地主成本。

## 六、Cellnex 自身的商业模式：资产、合同、单站经济与现金流

> 本章在第五章行业供需的基础上，回到 Cellnex 公司本身，回答五个问题：公司究竟卖什么，站址和权利如何取得，客户按什么合同付费，第二/第三租户为什么提高回报，以及收入如何依次转化为 EBITDAaL、RLFCF 和 FCF。

Cellnex 商业模式的闭环可以概括为：取得或建设优质站址，以长期锚定合同覆盖初始投资，在同一站址引入更多客户和设备占用，通过调价、工程及相邻服务扩大收入，再用土地管理和规模化运维控制成本；最终以项目回报、杠杆和自由现金流约束新增投资。[S01][S03][S24]

### 6.1 先用一句话和一座站点理解这门生意

**一句话定义。** Cellnex 向运营商出售的不是无线流量，也不主要是钢塔本身，而是“在正确地点长期、合法、稳定地安装和运行通信设备的权利与配套服务”。移动运营商拥有频谱、主动无线设备、核心网和终端客户；Cellnex 控制土地/屋顶、塔桅、机房、供电、安防、接入条件和部分回传，并负责这些资产长期可用。[S01][S06][S24]

先想象一个最简单的郊区宏站：

```text
手机用户
  ⇅ 无线信号
运营商 A 的天线、射频单元和基带设备        ← 主动设备，通常由 MNO 控制
运营商 B 的天线、射频单元和基带设备        ← 第二个 PoP / 共址租户
──────────────────────────────────
塔桅、支架、线缆通道、机房/机柜、供电、围栏 ← Cellnex 的基础设施服务
土地或屋顶使用权、规划许可、道路进入权       ← 站点能够存在的法律基础
光纤或微波回传                                ← 把站点接入更大的通信网络
```

这座站点至少涉及五个不同主体：地主把土地或屋顶使用权交给 Cellnex；Cellnex 投资或控制塔桅及配套设施；MNO 把自己的主动设备安装上去；设备商向 MNO 提供天线、射频和基带；最终用户向 MNO 购买通信套餐。Cellnex 通常不向手机用户收费，而是向 MNO 收取长期站点服务费，再向地主、能源商、施工和维护供应商付款。[S01][S06][S16]

#### 6.1.1 初次阅读必须分清的十个概念

| 概念 | 直观理解 | 为什么影响商业模式 |
|---|---|---|
| Site / 站点 | 能够部署通信设备的一个位置，不一定有独立铁塔，也可能是屋顶、烟囱、高杆或交通设施 | 站点是基本资产单元，但不同位置价值差异很大 |
| Tower / 塔桅 | 用来把天线抬高并固定的物理结构 | 只是站点的一部分；没有许可、电力和土地权利的塔不能形成服务 |
| Active equipment / 主动设备 | 发射、接收和处理无线信号的天线、射频和基带等设备 | 通常由 MNO 投资和控制，决定网络制式与容量 |
| Passive infrastructure / 被动基础设施 | 土地、塔桅、机房、支架、供电接入、围栏和安防等 | Cellnex 的核心资产和收费基础 |
| PoP | 某个客户在某个站点上的一个可计费网络存在点 | 一座站可以有多个 PoP；收入增长更应看 PoP 而非只看站点数 |
| Co-location / 共址 | 第二家运营商进入已有站点，或客户增加可计费设备占用 | 通常复用已有固定成本，是核心经营杠杆来源 |
| Amendment / 设备变更 | 原租户增加天线、频段、机柜、重量或功率 | 可能增加经常性费用和工程收入，但也可能需要加固 CapEx |
| BTS / Build-to-Suit | 根据锚定客户要求新找地点、新建站点 | 锁定长期需求，但先投入资本，初期通常只有一个租户 |
| Backhaul / 回传 | 把无线站点连接至汇聚网和核心网的光纤或微波链路 | 没有回传，塔上的无线设备无法把数据送往互联网和其他用户 |
| Neutral host / 中立宿主 | 不直接与 MNO 争夺终端用户，原则上允许多家运营商共享 | 使竞争对手愿意把关键被动设施交给同一平台运营 |

#### 6.1.2 为什么“一座站”和“一个 PoP”不是同一回事

如果 Cellnex 新建一座站，只有运营商 A 入驻，站点数增加 1，PoP 也增加 1，tenancy ratio 约为 1.0x。以后运营商 B 入驻，站点数不变，PoP 增加 1，tenancy ratio 提高；如果运营商 A 又因新增频段形成额外可计费占用，PoP 统计还可能继续变化，具体取决于公司定义和合同口径。

2025 年报披露约 111,752 个电信站点和约 180,856 个 PoP，简单相除约为 1.62x；H1 2026 公司披露 tenancy ratio 为 1.63x。[S02][S24] 这说明平均每个站点承载超过一个网络存在点，但不能理解为每座站都有 1.6 家独立运营商：有些核心城市站点可能承载多家客户，有些偏远 BTS 仍只有一个锚定租户，部分 PoP 还可能来自同一客户的不同配置。

**投资含义。** 站点数主要描述资产规模，PoP 和 tenancy ratio 更接近资产复用；但 tenancy ratio 也不是完美利润指标。若新增租户需要昂贵加固、供电升级或地主分成，第二个 PoP 的回报可能低于表面判断；若公司出售大量低租户站点，tenancy ratio 也会被动上升。因此必须同时看共址数量、Tower Expansion CapEx、站点处置和有机收入。

#### 6.1.3 一座站点上谁拥有、谁投资、谁承担风险

| 项目 | 通常控制/投资方 | 主要风险 | Cellnex 是否直接承担 |
|---|---|---|---|
| 频谱牌照 | MNO | 拍卖成本、覆盖义务、续期和监管 | 通常否，但决定客户部署计划 |
| 核心网与用户系统 | MNO | 技术、网络安全、用户流失和资费竞争 | 通常否；RANaaS 等例外业务边界更深 |
| 天线、射频、基带 | MNO 或其设备供应商 | 技术淘汰、容量、供应商切换 | 核心 Towers 通常否，工程改造时参与 |
| 土地/屋顶产权 | 地主或物业业主 | 产权、租约、重建和租金 | Cellnex 多通过租赁/使用权控制，承担续租和现金支出风险 |
| 塔桅和被动配套 | Cellnex、其他 TowerCo 或 MNO | 建设、结构、安全、维护和利用率 | 是核心风险 |
| 电力与备用能源 | 电网/能源商 + Cellnex | 并网、价格、停电和电池维护 | Cellnex 管理，部分成本可 pass-through |
| 光纤/微波回传 | MNO、Cellnex 或第三方网络商 | 路权、容量、冗余和故障 | 视合同而定；Cellnex 也销售 FTTT/连接服务 |
| 终端客户收入 | MNO | ARPU、竞争、流失率和坏账 | Cellnex 不直接承担零售风险，但承担 MNO 信用风险 |

这张表解释了 TowerCo 模式的边界：Cellnex 把“位置和物理基础设施风险”集中起来，MNO 保留“频谱、主动网络和终端客户风险”。这种专业化只有在共享所节省的重复投资、部署时间和运维成本，大于长期服务费及合同约束时，才对双方都有经济意义。

### 6.2 产业链中的资产流、服务流和资金流

只看“Cellnex 向 MNO 出租塔”仍然过于简化。TowerCo 同时组织三条方向不同的链：资产和权利从地主/MNO 流向 Cellnex，基础设施服务从 Cellnex 流向客户，现金则由终端用户经 MNO 流入 Cellnex，再流向地主、供应商和债权人。

#### 6.2.1 资产和权利如何形成

Cellnex 的站址组合主要可以通过四种方式形成：

1. **收购 MNO 的存量塔站。** MNO 把塔桅等被动资产卖给 Cellnex，同时签署长期 MSA/MLA，成为锚定客户。Cellnex 一次性支付收购款并接手维护、地主和运营责任，MNO 获得现金但承担未来服务费。
2. **收购其他 TowerCo 或站址组合。** Cellnex 获得现成的客户合同、租约和运维组织，经济价值取决于合同条款、客户集中、站址质量和可共址空间，而不只是塔数。
3. **Build-to-Suit。** MNO 给出目标覆盖位置和技术要求，Cellnex负责搜索、签地主、许可、建设和交付；MNO 按长期合同入驻。
4. **控制第三方位置。** Cellnex 与屋顶、土地、交通设施或公共资产业主签约，再把合格位置提供给一个或多个客户。部分位置只有租赁权，Cellnex并不拥有底层不动产。[S01][S03][S16]

因此，资产负债表上的有形资产只反映商业模式的一部分。站址价值还嵌在土地租约、客户 MSA、规划许可、进入权、转租权、运营流程和未来共址选择权中。两个账面成本相同的塔，如果一个位于三家 MNO 都需要的城市热点，另一个位于只有单一客户的低密度区域，其经济价值会显著不同。

#### 6.2.2 Cellnex 实际交付什么服务

| 服务阶段 | Cellnex 的工作 | 客户得到什么 | 可能对应的收入 |
|---|---|---|---|
| 站址搜索 | 根据 MNO search ring 寻找土地、屋顶或现有站点 | 满足射频规划的位置候选 | 可能包含在 BTS 或工程合同中 |
| 可行性和许可 | 产权核查、结构研究、规划/建设申请、社区与业主协调 | 一个法律和工程上可实施的站点 | 工程/研究费或项目成本 |
| 建设和适配 | 塔桅、基础、机房、围栏、供电、加固、线缆路径 | 可安装主动设备的被动基础设施 | BTS 长期服务费、工程费 |
| 安装与验收支持 | 协调吊装、设备布局、施工窗口和测试 | 缩短开站时间并满足技术规范 | 安装/工程服务收入 |
| 长期访问 | 允许客户持续占用空间、重量、电力和地面区域 | 稳定使用正确位置的权利 | 年度或季度基础服务费 |
| 运营维护 | 24x7 NOC、告警、现场维修、安全、能源和合规 | 可用性、故障响应和 SLA | 通常嵌入长期服务费，也可能单列 O&M |
| 扩容和变更 | 加天线、换设备、加固、扩电、增加回传 | 支持新频段、5G 或容量升级 | 新 PoP、amendment、工程费 |
| 去站和迁移 | 拆除重复设备、恢复场地、迁移到其他共享站点 | MNO 网络合理化和成本降低 | 去站工程费、补偿或递延收入，亦可能造成 churn |

Cellnex 官网把模式描述为从纯 co-location 向完整的 `site as a service` 演进，即在位置之外叠加绿色能源、韧性、高带宽连接和相邻服务；这是公司的战略定位，是否提高资本回报仍要看各服务的合同与 CapEx。[S06]

#### 6.2.3 钱最终从哪里来、流到哪里去

```text
消费者/企业/政府
  -> 向 MNO、公共部门网络或场所运营方支付通信与数字服务费用
MNO/政府/物业客户
  -> 向 Cellnex 支付基础服务费、调价、共址、工程、BTS、DAS 或连接费用
Cellnex
  -> 向地主支付土地/屋顶租金
  -> 向电力、光纤、施工、维护和设备供应商付款
  -> 支付员工、税费、利息和债务本金
  -> 用剩余现金维护、扩建、回购或分红
```

Cellnex 的核心 Towers 收入一般不是按终端流量分成。用户多看一小时视频，Cellnex 不会立即多收一笔钱；流量必须先让 MNO 产生覆盖或容量投资，再形成新增占用或合同变更。另一方面，一旦站点服务合同签署，短期用户流量下降也不一定立刻减少收入，因为基础费来自长期合同。这使业务收入比设备销售和零售通信更稳定，但也造成需求反应存在时间滞后。

#### 6.2.4 资产出售不是创造了“免费资本”

当 MNO 向 TowerCo 出售塔站时，交易同时发生两件事：MNO 收到一次性现金并减少被动资产管理工作；TowerCo 支付大额收购款并获得长期合同现金流。对 MNO 而言，这是把资产所有权和未来资本开支，换成长期、可能按 CPI 或固定比例调价的服务承诺；对 Cellnex 而言，这是先付出资本，再依赖锚定租户信用、合同期限和未来共址收回投资。[S01][S03]

所以不能简单说 TowerCo “替 MNO 降低了成本”。更准确的判断是：TowerCo 有机会通过多租户共享、专业运维和较低重复建设，把同一位置的总成本做得比各 MNO 分别持有更低；但若共址不足、融资昂贵、地租快速上涨或合同竞争不足，长期总成本未必下降。英国 CMA 对被动基础设施供应集中度的担忧正体现了这一边界。[S31]

### 6.3 收入形成机制

#### （1）存量基础服务费

锚定客户和次级租户按站址、设备、占用空间、地面面积、容量和剩余承载能力支付基础服务费。费用通常按月或按季收取，站址位置、设备类型和租户数量会显著影响年收入。[S01]

#### （2）价格调整

Cellnex 合同通常采用 CPI/RPI、通胀指数或固定比例 escalator。2024 CMD 的公司口径是约 65% 收入与 CPI 挂钩、约 35% 使用 1%-2% 固定 escalator，多数合同有 0% floor；部分 CPI 条款存在 cap，因此不能把“通胀挂钩”理解为完全无限的价格传导。[S03]

#### （3）新增共址和 PoP

新运营商进入已有站点、原运营商增加设备、5G 改造和特殊连接项目都会形成新增 PoP。共址的增量收入往往可以复用现有站址的土地、塔桅、供电、监控和部分维护成本，是 TowerCo 经营杠杆的核心来源。[S01][S02]

#### （4）Build-to-Suit 和工程服务

BTS 根据锚定客户覆盖需求建设新站，工程服务则包括结构计算、设计、现场勘察、适配、安装和调试。BTS 可锁定长期合同，但会在前期占用现金；工程服务通常是独立履约义务，利润率低于集团核心 EBITDAaL。[S01]

### 6.4 合同结构

- 合同形式通常包括 MSA（Master Service Agreement）、MLA（Master Lease Agreement）及具体项目、SLA 合同。
- 锚定客户合同一般有 10-20 年初始不可取消期限，并带多次续约；部分合同为长期或不定期限、自动延期，除非客户取消。
- 2024 CMD 披露 16 个锚定客户含续约的平均合同期约 31 年。
- H1 2026 的实际案例包括 Vodafone Spain 约 2,000 个现有 PoP 续约十年，以及 Sunrise 新增 300 个 BTS，原 MSA 为 `20+10+10` 年，之后转为无固定期限。[S01][S02][S03]

公司披露的 `EUR 110bn+ CPI` backlog 应视为管理层估计，而不是完全不可撤销的订单余额。年报明确说明该口径依赖续约假设，包含固定 escalator 但不包含未来通胀，部分合同在特定条件下可以较短通知取消。[S01][S03]

### 6.5 站址来源和土地关系

大部分塔站所在土地或屋顶通过第三方租约、转租或其他合同控制。Cellnex 会进行土地购买、长期使用权、租约续签、租金重谈和现金预付，以降低长期 lease cash-out 并改善项目经济性。[S01][S16]

土地和屋顶是业务的重要约束：站址不能只看物理位置，还要看规划许可、产权稳定性、可承载重量、供电、接入道路、光纤可得性和租约剩余期限。因此，拥有“站点数量”不等于拥有相同质量的现金流资产。

### 6.6 合同和定价：供需如何变成收入

公开资料没有给出 Cellnex 的标准站址价目表，因为站点服务不是完全标准化产品。价格通常在 MSA/MLA 和站点订单中约定，并受位置、塔型、高度、天线数量、重量、占用空间、地面面积、功率、回传、工程难度、合同期限和客户规模影响。[S01][S03]

#### 6.6.1 一份站点合同可能包含哪些经济元素

| 合同元素 | 经济含义 | 研究风险 |
|---|---|---|
| 基础服务费 | 客户持续使用位置和被动设施的经常性付款 | 单价、最低承诺和站点范围通常不完全公开 |
| CPI/RPI 或固定 escalator | 随通胀指数或固定比例逐年调价 | 可能有 cap、floor 和国家差异，未必覆盖全部成本通胀 |
| 新 PoP/共址费 | 新客户或新增可计费占用带来的收入 | 需确认是否需要大额加固 CapEx |
| 设备 amendment | 增加天线、重量、频段、功率或机柜后的费用变化 | 并非每次技术升级都形成同等经常性收入 |
| 工程和安装费 | 勘察、结构研究、设计、施工、安装和调试 | 可能是一次性、利润率低于核心站点服务 |
| 能源/公用事业 pass-through | Cellnex 先付后按合同转给客户 | 扩大报告收入但通常不形成同等利润 |
| BTS 建设及最低承诺 | 以锚定客户长期付款支持新站投资 | 回报依赖交付、信用、期限和未来共址 |
| 去站补偿/退出费 | 客户提前移除设备时的保护 | 可能延缓收入冲击，但不能永久消除 churn |
| SLA 奖惩 | 可用性、响应和交付不达标时的责任 | 故障和项目延期可能造成赔偿或客户关系损害 |

#### 6.6.2 单站经济性应该怎样理解

由于公司没有披露标准单站数据，下面只给出经济逻辑，不代入假设数字：

```text
单站经常性收入
  = 锚定客户基础费
  + 第二/第三租户共址费
  + 可经常性计费的设备扩容
  + 合同调价
  + 其他持续服务费

单站运营贡献（分析概念，并非公司披露指标）
  = 单站经常性收入
  - 地租/屋顶租金
  - 维护、安防、税费和不可转嫁能源
  - 站点直接运营成本

单站投资回报
  还必须扣除初始收购/BTS CapEx、后续加固扩容 CapEx、融资成本和最终退役成本
```

第一租户的重要性在于让站点从零收入变成有合同支持的资产；第二租户的重要性在于复用土地、塔桅、NOC 和大量固定成本；第三租户继续提高复用。但边际回报不会无限上升，因为塔体空间、风载、电力和地面区域有上限，后续租户可能需要越来越昂贵的改造。

#### 6.6.3 长合同为什么既是优势也是风险

长期 MSA 提高现金流可见性，使 Cellnex 可以使用长期债务融资，也降低 MNO 短期迁移意愿。但投资者必须拆开四个问题：

1. 合同“名义期限”是否依赖客户可选择的续约期？
2. 客户能否因 MNO 合并、覆盖变化或特定条件提前去站？
3. 调价是否有 cap，而地租和维护成本是否按更高比例上升？
4. 合同到期时，位置稀缺性是否足以支撑续约价格？

2024 CMD 的约 EUR 110bn + CPI backlog 是管理层估计，依赖续约和合同假设，不应视为不可撤销订单。长期合同降低年度波动，却把价值判断推向客户信用、续约条款和几十年的成本错配。[S01][S03]

#### 6.6.4 供给稀缺不一定立即转化为涨价

某个站点即使非常稀缺，Cellnex 也可能受既有 MSA 的定价公式约束；稀缺价值更可能通过新增客户报价、设备扩容费、续约谈判、较低 churn 或更强共址概率体现。反之，若当地存在另一个合格站、MNO 可以共享网络或重新规划，Cellnex 的议价能力会受限制。英国 CMA 的救济决定说明监管也会主动保护这种替代性。[S31]

### 6.7 收入、成本与利润率的区别

能源、公共事业费、部分业务费和客户预付款可能通过合同转嫁给客户，形成 pass-through 收入和成本。研究 Cellnex 时要同时看：

- **Operating Income**：法定/报告口径，可能包含 pass-through。
- **Revenues ex pass-through**：剔除波动性转收费项目，更接近可比经营规模。
- **Adjusted EBITDA**：公司定义的经营指标，并非 IFRS 标准指标。
- **EBITDAaL**：Adjusted EBITDA 扣除租赁付款后的指标，更适合观察租赁型基础设施的经营表现。
- **RLFCF**：Recurring Leveraged Free Cash Flow，反映扣除日常租赁、利息、维护 capex、税费等后的经常性现金流。
- **FCF**：公司定义为 RLFCF 扣除 BTS capex 和 Expansion capex；不是简单的净利润加折旧。[S01][S02]

### 6.8 从供需变化到财务报表：完整传导关系

理解商业模式后，还需要判断同一种业务变化会先出现在收入、利润还是现金流。TowerCo 最常见的误读，是把 EBITDA 增长直接等同于现金增长，或把 CapEx 下降直接等同于竞争力提高。

#### 6.8.1 不同增长方式进入报表的时间不同

| 经营事件 | 收入端 | 成本/利润端 | 资本开支与现金流 | 需要防止的误读 |
|---|---|---|---|---|
| 存量合同年度调价 | 基础费增加，进入有机收入 | 若地租和成本涨幅较低，利润率改善 | 通常不需要同等新增 CapEx | CPI 收入不等于净通胀保护，要比较成本 cap |
| 简单共址 | 验收后增加经常性 PoP 收入 | 复用站点固定成本，增量利润潜力较高 | 发生勘察、安装和有限适配 CapEx | 不能假设所有共址都是零 CapEx |
| 重大设备 amendment | 可能增加占用费和工程收入 | 工程收入利润率可能低于核心服务 | 可能需要塔体加固、扩电和地面扩容 | 收入增长可能伴随较高 Expansion CapEx |
| 新建 BTS | 验收/开站后逐步形成长期收入 | 初期单租户，固定成本分摊较弱 | 建设期先出现 BTS CapEx 和现金流出 | 当期 FCF 下降不一定意味着价值下降 |
| BTS 后续第二租户 | 新增经常性共址收入 | 固定成本进一步复用 | 若承载充足，增量 CapEx 较低 | 这是 BTS 长期回报改善的关键，但公司未披露完整成熟曲线 |
| 能源 pass-through 上升 | Operating Income 表面增加 | 对 EBITDA 的贡献通常有限 | Cellnex 先付能源再向客户转收，影响营运资金 | 不能把 pass-through 当作核心增长 |
| MNO 去站/churn | 合同保护期后经常性收入减少 | 站点固定成本未必同步消失 | 可能发生拆除和恢复成本 | Gross PoP 增长可能掩盖较高 churn |
| 收购站点组合 | 合并日起增加收入 | 增加折旧、租赁、整合成本和潜在商誉风险 | 先发生大额 M&A 现金流出，常伴随融资 | 报告增长不等于有机增长，也不等于行业需求增加 |
| 出售资产 | 可比收入基数下降 | 可能确认处置损益 | 获得处置现金，可用于降债或股东回报 | FCF/现金改善可能来自缩小资产组合 |

#### 6.8.2 为什么要同时看 Adjusted EBITDA、EBITDAaL、RLFCF 和 FCF

Cellnex 使用多层 APM 描述经营和现金：[S01][S24]

```text
Adjusted EBITDA
  - ordinary lease instalments
  = EBITDAaL

EBITDAaL 出发
  - 维护资本开支
  - 净现金利息、税费
  - 营运资金及经常性少数股东分配等
  = RLFCF

RLFCF
  - Expansion CapEx
  - BTS CapEx / Remedies
  = Company FCF
```

这几层正好对应 TowerCo 的供需经济：

- **Adjusted EBITDA** 能显示站点服务的高经营利润，但尚未完整反映大量土地/屋顶租赁现金负担。
- **EBITDAaL** 扣除正常租赁付款，更接近站址权利成本后的经营能力。
- **RLFCF** 再考虑维护、利息、税和营运资金，显示存量网络可重复产生的现金。
- **FCF** 再扣除共址扩容、相邻业务扩张和 BTS 建设，显示增长投资后剩余现金。

因此，需求旺盛可能出现两种完全不同的财务表现：如果主要是存量站点简单共址，收入、EBITDAaL、RLFCF 和 FCF 可能共同改善；如果主要是大规模 BTS，订单和未来收入增强，但当期 FCF 可能因建设现金流出下降。反过来，削减 BTS 会迅速改善 FCF，却可能减少未来可共址的新站点。

#### 6.8.3 用 FY2025 数据观察这种张力

FY2025 公司披露 Revenues ex pass-through 约 EUR 3.995bn、有机增长约 5.8%，Adjusted EBITDA 约 EUR 3.317bn，EBITDAaL margin 62.2%，RLFCF 约 EUR 1.913bn，但 Company FCF 只有约 EUR 350m；总投资约 EUR 1.031bn。[S01]

这些数字不是矛盾，而是说明：

1. 存量合同、共址和经营效率能够形成较高 EBITDAaL 与经常性现金。
2. 土地租赁、利息、税、维护和营运资金会把 EBITDA 转成更低的 RLFCF。
3. Expansion CapEx 与 BTS/Remedies 又吸收大量 RLFCF，因此最终 FCF 远低于 EBITDA。
4. 判断业务改善必须看 FCF 增长来自收入/利润率提高，还是来自暂时减少增长投资。

#### 6.8.4 一座 BTS 的非数字化现金流示例

以下仅说明方向，不代表 Cellnex 披露的标准项目：

```text
开发期：选址、许可、设计、建设、并网
  -> 现金流为负，尚无或只有有限收入

锚定客户开站
  -> 开始收基础服务费
  -> 同时支付地租、维护、能源和融资成本
  -> 站点仍是单租户，回报主要由锚定合同支撑

第二客户共址
  -> 增加经常性费用
  -> 若结构余量充足，只需有限适配
  -> 单站运营贡献和资本回报提高

第三客户或设备扩容
  -> 继续增加收入，但可能触发加固、扩电和空间瓶颈

合同续约或退网
  -> 续约价格、地租续签和剩余技术需求决定终值
  -> 若退网，可能发生拆除与恢复成本
```

这个例子解释了为什么 Cellnex 当前战略强调项目级税后无杠杆 IRR、选择性 BTS 和存量共址：公司不再只追求“多建塔”，而是要求每一笔前期资本能够被长期锚定收入和后续共享覆盖。[S02][S03]

#### 6.8.5 最终需要建立的因果仪表盘

```text
行业层：流量、频谱、覆盖义务、MNO 竞争和资本开支
  ↓
订单层：共址、amendment、BTS、DAS、Fiber、续约和去站
  ↓
运营层：Gross PoP - churn = Net PoP；tenancy；交付周期；站点可用性
  ↓
收入层：基础费 + escalator + 新 PoP + 工程 + pass-through
  ↓
利润层：收入 - 地租 - 维护 - 人员 - 不可转嫁能源与其他成本
  ↓
现金层：EBITDAaL -> RLFCF -> 扣 Expansion/BTS CapEx -> FCF
  ↓
资本配置：降债、维持评级、再投资、回购和分红
```

如果只看链条中的一个指标，结论可能完全错误。例如：塔数增加可能只是低回报 BTS；收入增加可能只是能源 pass-through；EBITDA 增加可能尚未反映租赁现金支出；FCF 增加可能来自削减未来增长投资；tenancy ratio 上升也可能来自处置低租户站点。

### 6.9 商业模式闭环、成立条件与失效方式

| 环节 | Cellnex 的动作 | 价值来源 | 主要失效方式 |
|---|---|---|---|
| 取得资产 | 收购、租赁、购买权利或 BTS 建设站址 | 获得特定位置的长期经营权和客户合同 | 收购价格过高、租约短、许可或权利不稳定 |
| 锚定现金流 | 与大型 MNO 签长期 MSA/MLA 或项目合同 | 覆盖初始投资并提高融资可见性 | 客户信用恶化、去站条款宽松、续约价格下降 |
| 增加共址 | 引入第二、第三客户或增加可计费设备 | 复用土地、塔桅、NOC 和维护固定成本 | 没有第二客户需求，或加固/扩电成本过高 |
| 合同增长 | CPI/固定 escalator、amendment、工程和服务升级 | 在不新增站点的情况下提高单站收入 | 调价有 cap，地租和维护成本涨得更快 |
| 运营提效 | 集中采购、数字化、NOC、地主和能源管理 | 扩大 EBITDAaL 和经常性现金转换 | 服务质量下降、故障、供应商和合规成本上升 |
| 再投资 | 选择性 BTS、Expansion CapEx 和相邻业务 | 扩大未来站址池和客户关系 | 项目 IRR 低、建设延期、资本成本和杠杆过高 |
| 资本分配 | FCF 用于降债、维持评级、回购和分红 | 把基础设施现金流转化为股东回报 | 过度分配挤压维护、增长投资或评级空间 |

**商业模式成立的必要条件**不是“塔越多越好”，而是站址位置有持续网络需求、锚定合同能够覆盖初始资本、未来存在共址或扩容空间、客户调价足以覆盖地主和运营成本，并且融资成本低于项目长期回报。

**商业模式最重要的正循环**是“优质站址 -> 锚定客户 -> 第二/第三租户 -> 单站现金回报提高 -> 支持更多高回报投资”；最主要的反循环则是“MNO 合并或需求不足 -> churn/无共址 -> 单站回报下降 -> 减值或削减投资 -> 未来增长池收缩”。因此，对 Cellnex 的估值不能只看站点数量和合同名义年限，还必须看 PoP、tenancy、churn、地租、Expansion/BTS CapEx、RLFCF、FCF 和项目回报。

## 七、成本结构、资本开支和现金流

### 7.1 主要成本

1. **土地和屋顶租金**：大部分站点使用第三方土地或屋顶，租金是长期、刚性成本。
2. **能源**：电力和备用能源成本高，但约 80% 直接向租户传导，剩余暴露通过远期合同和 PPA 等方式管理。[S02]
3. **维护和修理**：站址、塔桅、能源、机房、网络和安全系统的日常维护。
4. **税费和许可**：地方物业税、业务费、规划和许可成本。
5. **人员、NOC 和供应商**：工程、监控、客服、项目管理、采购和外包供应商。
6. **财务成本**：长期债务、租赁负债和再融资成本会直接影响权益现金流。

Cellnex 的经营杠杆来自收入增长快于可控成本增长，但租金和维护成本的增长可能高于客户合同的固定 escalator，形成通胀错配。公司通过集中采购、供应商优化、工作流自动化、土地管理和 AI 应用改善利润率。[S01][S02]

### 7.2 资本开支分类

| Capex 类别 | 典型用途 | 对现金流的影响 |
|---|---|---|
| Maintenance capex | 维持安全、供电、可用性和站址状态 | 保持收入基础，通常不能长期削减 |
| Tower Expansion capex | 现有塔站适配新租户、加固、升级 | 以新增 PoP 和租户收入为目标 |
| Other Business Expansion capex | DAS、主动设备、光纤、网络和其他相邻业务 | 资本密度和回报因业务而异 |
| Efficiency capex | 去站、土地预付、能源和连接效率 | 以提升 RLFCF 为目标 |
| BTS capex | 按锚定客户需求建设新站 | 锁定长期收入，但前期占用现金、初期租户少 |
| M&A capex / divestments | 购买资产、土地和长期使用权，或处置资产 | 决定平台规模和资本结构 |

FY2025 总投资约 EUR 1,031m，低于 FY2024 的 EUR 1,318m；FCF 为 EUR 350m，高于 FY2024 的 EUR 328m。H1 2026 FCF 增至 EUR 301m，管理层将改善归因于经营执行、资本结构优化、债务成本和 BTS capex 强度下降。[S01][S02]

### 7.3 BTS 与共址的现金流张力

```text
BTS：先投入土地/许可/建设/供电
  → 先只有锚定客户
  → 交付后形成长期基础费
  → 后续增加共址，改善 tenancy ratio 和增量回报

共址：已有站点增加租户
  → 复用大量固定成本
  → 增量收入较快转为经营现金流
```

因此，BTS 不是坏业务，而是需要用项目级回报、合同期限、锚定客户信用和后续共址潜力来筛选。短期 FCF 改善如果主要来自削减 BTS，而不是提高站点收入和运营效率，也需要谨慎看待。[S01][S02]

## 九、管理层、战略、资本配置与薪酬

> **分析时点：2026 年 8 月 7 日。** 本章把四类信息分开处理：公司披露的治理和薪酬事实、管理层提出的战略目标、截至目前已经完成的动作，以及分析师对其质量和可持续性的判断。管理层对战略的表述不等于战略已经实现，薪酬指标达标也不等于长期股东价值已经创造。

### 9.1 本章关键术语

| 术语 | 含义 | 对投资者的重要性 |
|---|---|---|
| Board of Directors / 董事会 | 股东选举的最高监督和重大决策机构 | 决定 CEO 任免、预算、重大投资、资本结构、分红和薪酬政策 |
| ExCom / 执行委员会 | CEO 领导的最高经营管理团队 | 负责将董事会批准的战略落实到职能、国家和业务线 |
| Independent Director / 独立董事 | 不代表特定大股东、原则上与公司不存在影响独立判断的重大关系 | 独立董事比例越高，理论上越有利于保护全体股东，而非只服务于管理层或某一大股东 |
| Proprietary Director / 股东代表董事 | 由持有重要权益的股东提名或代表该股东利益的董事 | 可以带来资本纪律和行业经验，也可能使决策更接近特定股东偏好 |
| ARMC | Audit and Risk Management Committee，审计与风险管理委员会 | 监督财务报告、内控、审计、风险和绩效指标的财务数据基础 |
| NRSC | Nominations, Remunerations and Sustainability Committee，提名、薪酬与可持续发展委员会 | 提名董事和高管、设计薪酬、评估绩效并监督可持续发展 |
| CAC | Capital Allocation Committee，资本配置委员会 | 审阅商业计划、预算、股息政策、重大投资和 M&A 规则 |
| STI / Annual Variable Remuneration | 一年期奖金 | 观察管理层当年被鼓励追求收入、利润、现金流还是资本回报 |
| LTIP | Long-Term Incentive Plan，长期激励计划 | 通常以三年绩效和股份结算，将 CEO 收益与长期股东结果联系起来 |
| TSR | Total Shareholder Return，股东总回报 | 股价变化加股息和回购分配；可用绝对值或与同业比较的相对值衡量 |
| RLFCF / Share | 每股经常性杠杆自由现金流 | 关注利息、税和少数股东分配后的经常性现金，但不等同于扣除全部扩张和 BTS 投资后的 FCF |
| Malus / Clawback | 奖金削减或追回机制 | 财务重述或严重不当行为发生后，公司可取消未付奖金或追回已付奖金 |

### 9.2 谁监督管理层：董事会和三个委员会

截至 2025 年末，Cellnex 董事会由 10 人组成，其中 6 名独立董事、3 名股东代表董事和 1 名执行董事，即 CEO Marco Patuano；女性董事 4 人，占 40%。独立董事 Óscar Fanjul 担任董事长，董事长与 CEO 分设。2025 年董事会召开 11 次会议，现场出席率 98.3%。[S01][S33]

2026 年 4 月 30 日股东大会又将董事任期由三年改为一年，连任现任董事，并新任命独立董事 Cynthia Gordon 和 Kais Ben Hamida，将董事会人数增至 12 人；7 月 30 日，GIC 的股东代表由 Alexandra Reich 更替为 Laura Abasolo。按 2026 年 8 月官网名单，当前董事会为 8 名独立董事、3 名股东代表董事和 1 名执行董事，独立董事占 66.7%；女性 5 人，占 41.7%。一年一选提高了股东问责频率，但也使董事会更容易受到年度投票和短期股东压力影响。[S14][S37]

|---|---|---:|---|---|
| 董事会 | 8 独立、3 股东代表、1 执行 | 11 次；98.3% | 战略、预算、重大交易、资本结构、CEO 和薪酬的最终决策 | 独立董事占三分之二、董事长与 CEO 分设，是基本治理优势 |

CAC 的三名股东代表分别对应 Edizione、GIC 和 TCI，均具有投资、通信或基础设施经验。这样的组成可能使资本配置讨论更强调现金回报、估值和投资纪律；另一面是独立董事不占多数，资本配置可能更接近几名大股东的期限、流动性或回报偏好。公司披露 CAC 不包括 CEO，重大事项最终仍由全体董事会决定，这降低了 CEO 单方面扩张的风险，但不能完全消除大股东偏好的影响。[S33]

### 9.3 谁在经营公司：Marco Patuano 与 2026 年新 ExCom

**组织设计的正面含义。** Cellnex 已完成大规模跨国并购，下一阶段确实更需要统一数据、采购、资产管理和项目回报标准。CFO 同时掌握控制与采购，有利于把站点成本、供应商合同和资本预算放在同一套经营控制下；COO 统一客户与技术运营，有利于复制共址、土地和维护效率。

**执行风险。** 地方许可、地主谈判、监管和 MNO 客户关系高度本地化。总部集中化若过度，可能牺牲响应速度；Northern Europe 一名负责人同时覆盖五国，管理跨度较大；Vertical Solutions 既要集中治理又要本地交付，权责界面仍需经营数据证明。新架构于 2026 年 2 月才生效，不能因组织图看起来更简洁就提前确认协同已经实现。

**人才结构短板。** 2025 年末，公司按监管口径披露的 Senior Management 中仅 1 名女性，占 7.14%；ExCom 与 n-2 合计口径为 24%。2026 年公布的新 ExCom 十人名单中未见女性成员，与董事会 40% 女性占比形成明显反差。公司将女性管理层列为 ESG 目标，但最高经营层的多样性仍需实际改善，而不能只依靠董事会层面的比例。[S33][S35]

### 9.4 战略转型：从“买更多塔”到“经营好每座塔和每一欧元资本”

Cellnex 早期战略以收购运营商塔站和进入新国家为主。规模扩张形成了欧洲最大独立 TowerCo、长期合同和跨国客户平台，也留下了约 EUR 20bn 净债务、复杂的国家组合、土地租约和 BTS 承诺。Marco Patuano 任内延续并强化的“下一章”战略，不再把资产数量作为首要目标，而是强调有机共址、效率、现金转换、投资级评级、组合处置和股东回报。[S01][S03]

| 战略轴 | 管理层采取的动作 | 截至 FY2025/H1 2026 的可验证结果 | 尚未证明的部分 |
|---|---|---|---|
| 聚焦核心资产 | 出售爱尔兰和奥地利业务；处置西班牙、法国非核心数据中心；停止西班牙 O&M；引入 Stonepeak 持有北欧少数股权 | 组合更集中，处置资金可用于降债和提高财务灵活性 | 需核对处置价格、税后所得和出售资产的原始资本回报，才能判断是否真正创造价值 |
| 有机增长优先 | 共址、选择性 BTS、5G 改造、Tower rationalization 和 Collocation-to-Suit | 2025 净 PoP 增长 4.5%，Towers 有机收入增长 5.5%；约 3,700 个 BTS 和 16,000 次技术升级 | 新 BTS 的单站 IRR、回收期及后续共址率仍未完整披露 |
| 延长客户合同 | 与 MasOrange、ODIDO、Fastweb/Vodafone 等续约或扩展合作 | 提高收入可见性，强化西班牙、荷兰、意大利的锚定客户关系 | 续约中的价格、去站权、RAN sharing 和 capex 承诺需结合合同条款评价 |
| 提高运营效率 | 集中采购、供应商优化、约 10% 土地租约重谈、AI、Digital Twin 和组织集中化 | FY2025 EBITDAaL margin 为 62.2%，高于 FY2024 的 60.6%；H1 2026 EBITDAaL 有机增长 7.7% | 2024 CMD 的 2027 年 64% margin 目标尚未到验证期；需区分真实效率与处置、投资减少的影响 |
| 改善现金和杠杆 | 减少投资、推动 RLFCF/FCF、保持 BBB- | FY2025 RLFCF EUR 1,913m，FCF EUR 350m；薪酬口径净债务/EBITDA 为 6.04x，已接近 5.0-6.0x 区间 | 净金融债务仍约 EUR 20.8bn，FY2025 较 FY2024 并未明显下降；RLFCF 与最终 FCF 之间仍有较大落差 |
| 向股东返还现金 | 2025 年执行 EUR 1bn 回购；2026 年启动 EUR 500m 股息并计划额外回购 | 管理层已从承诺阶段进入实际返还阶段 | 回购是否增值取决于成交估值和资金来源；以重新加杠杆支持回报不等于经营创造了同等现金 |
| 重塑组织 | 2025 年统一各国 COO 相关职能；2026 年将 ExCom 压缩为四大职能、四个区域和 Vertical Solutions | 决策链条更清晰，采购、运营和区域责任被明确 | 新架构运行时间短，国家客户满意度、项目交付和费用节约尚需后续数据验证 |

**初步判断：战略方向已经改变，执行也已开始产生经营结果，但尚未完成价值证明。** 组合处置、投资级评级、margin 扩张、现金回报和组织重构说明这不是口号式转型。另一方面，净债务绝对额仍高，2025 FCF 仅为 RLFCF 的一小部分，2023-2025 LTIP 又因 TSR 未过门槛而归零，说明经营改善尚未完整转化为长期股东回报。[S01][S02][S32]

### 9.5 资本配置：规则、资金来源与实际执行

2024 CMD 给出的资本配置框架有三层：第一，维持投资级评级并将净债务/EBITDA IFRS 16 控制在 5.0-6.0x；第二，产业投资必须符合战略，并达到高于 WACC 加国家、业务和安全边际风险溢价的回报门槛；第三，在 2026-2030 年至少分配约 EUR 3bn 股息，其余资金在回购、特别股息和产业投资之间选择。[S03]

| 优先级 | 公司规则/目标 | 已执行事项 | 分析师评价 |
|---|---|---|---|
| 1. 保护信用评级和流动性 | BBB-；长期杠杆 5.0-6.0x | S&P 与 Fitch 均为 BBB-；FY2025 薪酬口径杠杆 6.04x | 已进入目标区间附近，但 5-6x 本身仍属高杠杆，评级缓冲不能视为宽裕 |
| 2. 维护和优化现有资产 | 维护 capex、买地、租金预付和重谈、塔站合理化 | 约 10% 土地租约重谈，集中采购和供应商优化 | 这类投资可直接保护 EBITDAaL 和合同久期，通常优先级合理，但需披露土地投入回报和回收期 |
| 3. 有机增长 | 共址优先；BTS 和相邻业务按风险调整 IRR 筛选 | 2025 约 3,700 BTS、16,000 次技术升级；继续 DAS、韧性和垂直解决方案 | 共址资本效率通常较高；BTS 和主动设备必须单独核算，不能只看收入增长 |
| 4. 组合调整 | 出售非核心、低协同或不满足回报要求的资产 | 爱尔兰、奥地利和部分数据中心处置，西班牙 O&M 退出 | 战略逻辑清楚，但缺少收购成本、持有期现金流与出售所得的完整回报桥接 |
| 5. 最低股息 | 2026 年起最低 EUR 500m，之后最低年增 7.5%；2026-2030 累计约 EUR 3bn | 2026 年 EUR 500m 股息已经启动 | 可见性高，但刚性增长承诺会在行业下行或再融资恶化时压缩投资弹性 |
| 6. 回购/特别股息/产业机会 | 超额资本择优配置；回购应增厚每股价值 | 2025 年 EUR 1bn 回购，2026 年继续规划回购 | 只有回购价格低于内在价值且不削弱评级或高回报投资时才创造价值 |

公司在 CMD 中称到 2030 年可形成超过 EUR 10bn 的累计可配置现金，其中约 EUR 3bn 为最低股息，超过 EUR 7bn 用于回购、特别股息或产业投资。这个数字并不是单纯由经营 FCF 累积而来，其演示明确假设可以重新加杠杆至约 5.5x。因此应将其理解为“经营现金、资产处置和债务容量的合计资金池”，不能直接理解为未来六年将创造 EUR 10bn 自由现金流。[S03]

**资本配置的核心矛盾。** 公司一方面强调去杠杆和投资级评级，另一方面又把回到 5.5x 附近的债务容量视为可分配资本。若 EBITDA 增长使杠杆自然下降，随后再借债回购股票，股东回报的一部分来自提高财务风险，而非降低净债务。该策略可能在股价显著低估时增厚每股价值，但在估值不便宜、利率上升或 MNO 整合加速时会削弱缓冲。[S03]

**治理约束有形但仍需验证。** 公司披露以 Golden Rules、董事会监督和严格授权门槛管理投资，CAC 也频繁开会。优点是 CEO 不能单独决定重大 M&A；不足是项目最低股权 IRR、不同业务的风险溢价和历次投资后评估没有完整公开，外部投资者无法独立复核每项 BTS、土地和相邻业务投资是否真正超过资本成本。[S01][S03][S33]

这张表反映出两个不同结论。第一，收入、EBITDAaL 和经常性现金流只是略高于目标，杠杆指标则优于最高档，是奖金超过 100% 的主要来源。第二，现金股东回报率 4.27% 仅略高于 4.26% 门槛，说明 EUR 1bn 回购并未把该指标推到目标档；公司并没有将“做了回购”直接视为满分。[S32]

更重要的是，2023-2025 LTIP 没有归属。该计划要求 TSR 达到最低门槛，起始三个月 VWAP 为 EUR 32.46，公司披露的门槛对应 EUR 34.08；截至 2026 年初的三个月 VWAP 加分红仅 EUR 26.95。董事会没有因为经营指标改善而豁免门槛，最终支付为零。这是薪酬制度中最有说服力的 pay-for-performance 证据，也说明同一时期长期股东体验弱于管理层的经营叙事。[S32]

### 9.7 2026 年薪酬设计：更强调每股现金与 TSR

2025 年股东大会以 97.75% 的赞成票批准适用于 2026-2028 年的薪酬政策。相较旧政策，LTIP 总上限由目标值的 610% 降至 275%，取消股票期权，CEO 最低持股要求由两倍提高至三倍固定薪酬；这些调整来自公司与机构投资者和代理投票顾问的沟通。[S32][S34]

| 2026 CEO 薪酬模块 | 设计 |
|---|---|
| 固定薪酬 | EUR 1.3m；另有 EUR 125k 董事费 |
| 养老金与福利 | 养老金为固定薪酬 25%，实物福利为 5% |
| STI 目标/上限 | 目标为固定薪酬 100%；标准最高为目标 150%，并保留 0.8-1.2 领导力修正机制 |
| STI 指标 | 收入、EBITDAaL、RLFCF、调整后净债务/EBITDA、现金股东回报，各 20% |
| 2026-2028 LTIP 目标 | 固定薪酬的 183%，即按授予时价值约 EUR 2.379m，覆盖三年而非每年支付 |
| LTIP 总上限 | 目标的 275%，约 EUR 6.542m；属于授予价值口径，最终股份价值还会随股价变化 |
| LTIP 结算 | 三年考核，原则上 100% 以股份交付 |
| 持股要求 | 2028 年 6 月 4 日前持有相当于三倍固定薪酬，即约 EUR 3.9m 的股份 |

2026-2028 LTIP 的权重如下：[S32]

| 长期指标 | 权重 | 门槛支付 | 目标支付 | 单项最高支付 | 经济含义 |
|---|---:|---:|---:|---:|---|
| 绝对 TSR | 30% | 目标奖励的 50% | 100% | 400% | 要求股东获得绝对正回报，而非只跑赢弱势同业 |
| 相对 TSR | 20% | 50% | 100% | 400% | 与通信基础设施同业比较，控制行业共同波动 |
| RLFCF / Share | 35% | 50% | 100% | 150% | 强调经常性现金和每股价值，兼顾债务、利息和股本数量 |
| Scope 3 绝对减排 | 15% | 50% | 100% | 150% | 与 2020 基准和 SBTi Net Zero 路径挂钩 |

计划还设置总体 gate：至少满足以下之一才会归属，即绝对 TSR 达到门槛、相对 TSR 达到目标，或 RLFCF/Share 达到目标；若三者均不满足，所有奖励归零。单项 TSR 虽可达到 400% 支付，但全计划上限仍为目标值的 275%。公司不再事前公布 2026-2028 各指标的具体数值门槛，理由是保护竞争敏感信息，承诺计划结束后完整披露。[S32]

截至 2025 年末，CEO 仅持有 18,500 股，以公司采用的 EUR 26.81 VWAP 计约 EUR 496k，相当于固定薪酬的 0.4 倍，距离三倍要求仍远。公司给出的达标期限是 2028 年 6 月，因而当前不构成违约，但在真正形成显著自有资本风险前，不能仅凭未来持股要求认定利益已经完全一致。股东大会已批准 64,747 股 buyout award，现有资料仍未单独确认税后净交付股数；即使交付，这也是对其放弃前雇主激励的补偿，并非 CEO 以自有资金买入。[S32][S37]

### 9.8 薪酬与股东利益的一致性：优点和缺口

**正面因素。** 2026-2028 LTIP 中，绝对 TSR、相对 TSR 和 RLFCF/Share 合计占 85%，比单纯奖励资产规模、站点数或 EBITDA 更接近股东结果；三年期、股份结算、持股要求和 gate 进一步强化长期性。2023-2025 LTIP 实际归零，证明门槛不是装饰。旧计划最高可支付目标的 610%，新政策降至 275%并取消期权，也显著降低了凸性过强的风险。[S32]

**缺口一：没有直接的 ROIC 或项目 IRR 指标。** 战略反复强调每项投资超过 WACC 和风险溢价，但 CEO 的 STI/LTIP 没有明确列出 ROIC、ROCE、经济利润或新投资实际 IRR。管理层可能通过削减投资、出售资产或回购缩小股数提高每股现金流，而不一定证明历史和新增资本获得了足够回报。

**缺口二：RLFCF 不是最终 FCF。** 2026-2028 LTIP 把原有累计 FCF 换成 RLFCF/Share。公司披露的 RLFCF/Share 公式扣除营运资本、利息、税和少数股东经常性分红，但不扣除扩张和 BTS capex。它适合衡量存量资产经常性现金能力，却可能弱化对增长资本支出的约束。回购减少流通股数还会机械提高每股值，因此必须与总 FCF、净债务和投资回报一起看。[S32]

**缺口三：短期奖金直接奖励现金分配。** 将股息和回购列为 STI 指标能迫使管理层兑现回报承诺，但也可能鼓励在估值不合适或债务缓冲有限时分配现金。绝对 TSR、相对 TSR和杠杆指标提供了部分制衡，却不能替代逐笔回购估值和资金来源分析。

**缺口四：主观修正和信息透明度。** 领导力模型可将 STI 结果乘以 0.8-1.2，NRSC 也可在特殊事项下调整指标；2025 年乘数为 1，尚未出现明显滥用。2026-2028 LTIP 又停止事前披露具体门槛，外部股东在三年内无法判断目标是否足够有挑战性，只能等待事后结果。[S32]

**合同保护的双面性。** CEO 无故被解聘时可获得 6 个月固定薪酬。2026 年股东大会又将离职后竞业限制期由 24 个月缩短至 18 个月，但补偿仍为 18 个月固定薪酬，因此解聘补偿与竞业补偿合计最高仍相当于两年固定薪酬；大会还允许 CEO 在首次任命满三年后自愿辞职时保留已累积养老金权益。good leaver 可按任职期和业绩保留部分 STI/LTIP。发生 30% 以上控制权变更时，非股价指标按 100%处理、股价指标按交易价格计算并按比例现金结算。这些条款有助于招聘和保持战略独立，但竞业义务缩短而补偿不降、以及控制权变更时非 TSR 指标自动按目标完成，均使保护略偏向 CEO。[S32][S34][S37]

STI 的 malus/clawback 复核期为支付后 12 个月，LTIP 为支付后 3 年；财务重述或严重不当行为可触发取消、重算和追回。非执行董事从 2025 年起须将 20%-100% 固定董事薪酬以股份或递延股份权利取得，并原则上持有至离任，有利于让监督者也承担股价结果。[S32][S34]

### 9.9 对管理层的综合评价

| 维度 | 当前评价 | 主要依据 |
|---|---|---|
| 战略清晰度 | 较强 | 已明确从 M&A 扩张转为有机增长、效率、现金和股东回报，组织结构也随之调整 |
| 执行进度 | 中上，但尚未完成 | 组合处置、投资级评级、margin 和 H1 2026 FCF 改善可验证；新组织和 2027 目标仍待兑现 |
| 资本纪律 | 制度较完整，结果仍需验证 | 有 CAC、Golden Rules、杠杆区间和投资回报门槛；但项目 IRR、处置回报和回购估值披露不足 |
| 薪酬一致性 | 明显改善 | LTIP 归零、85% 长期权重指向 TSR/每股现金、上限降低、期权取消和持股要求提高 |
| 治理独立性 | 总体合格，CAC 需关注 | 董事会与 NRSC 独立董事占多数；CAC 股东代表占 60% |
| 人才与组织 | 专业背景匹配，转型风险较高 | CEO/CFO/COO/CSO 经验与当前阶段匹配；新 ExCom 刚组建且最高管理层性别多样性不足 |

**综合判断。** Marco Patuano 管理层已经把 Cellnex 从“规模优先”推向“现金和每股价值优先”，并在资产组合、评级、效率、组织和回报政策上采取了实质动作。当前最合理的评价不是“转型成功”，而是“方向可信、早期执行有效、长期价值尚待证明”。真正的证明标准应是：在不重新显著提高风险的前提下，2026-2027 年 FCF 持续扩大，净债务/EBITDA稳定在目标区间，新增 BTS 和相邻业务回报超过资本成本，回购价格具有增值性，并最终使 TSR 和每股内在价值同步改善。[S01][S02][S03][S32]

后续应重点跟踪：CEO 自有资金持股进度；2024-2026 和 2025-2027 LTIP 的实际归属；回购平均成本与注销股数；净债务绝对额和杠杆；RLFCF 到 FCF 的桥接；新增投资的 IRR/回收期；处置所得用途；CAC 对重大投资和股东回报的批准逻辑；新区域集群的客户满意度、交付速度和成本协同。

## 十、客户价值、竞争壁垒与竞争限制

### 10.1 对客户的价值

对 MNO 而言，Cellnex 的价值主要是：

- 把塔站和站址资本开支转成长期服务支出。
- 缩短 4G/5G 部署时间，减少选址、许可、建设和运维工作。
- 通过共享站点减少重复建设。
- 在运营商并购或网络整合后，执行去站和网络合理化。
- 提供室内、地下、交通枢纽、偏远区域和高密度城市覆盖。
- 通过能源韧性和电池项目提高通信连续性。[S06][S07]

### 10.2 主要壁垒

**站址和许可壁垒。** 优质屋顶、高塔、交通枢纽和特殊位置稀缺，重新获取许可耗时且存在监管不确定性。

**长期合同壁垒。** MSA/MLA、自动延期、设备迁移成本和锚定客户关系提高客户切换成本，但不等于合同永远不可取消。

**地主关系和租约管理。** 大量土地、屋顶和租约需要长期维护，能够买地、续租、重谈和预付租金的运营商更有机会保护现金流。

**多国运维平台。** NOC、工程、采购、维护、供应商和数字化系统可以跨站点复用。

**中立性。** Cellnex 不直接向 MNO 的终端用户提供移动通信，能够承载多家相互竞争的运营商。

**规模和密度。** 更多站点带来更强的客户覆盖、工程采购和跨业务交叉销售能力。

### 10.3 壁垒的限制

这些壁垒更像基础设施网络和合同壁垒，不是专利垄断。MNO 仍可能通过自建、网络共享、主动设备整合、租户合并和去站降低需求；TowerCo 之间也会在新站、租金、服务质量和续约条件上竞争。[S01][S03]

## 十一、治理、可持续发展与监管因素

管理层、董事会、资本配置委员会和薪酬计划已在第九章展开。本章只保留与经营许可、可持续发展和监管有关的事项。2025 年末董事会独立董事占 60%、女性占 40%；2026 年增加两名独立董事并发生一名股东代表更替后，当前比例分别约为 66.7%和 41.7%。[S14][S33][S37]

Sustainability Master Plan 2030 将目标分为 Resilient infrastructures、Climate action、Customer focus & Business conduct、People first。官网披露的公司目标包括：[S13]

- 2030 年 Scope 1/2 绝对排放较 2020 年降低 70%。
- 2025-2030 年使用 100% renewable electricity。
- 2030 年覆盖 82% 供应商和客户排放的 SBT。
- 与客户约定 5,000 个使用锂离子电池的站点。
- 所有高/极高气候风险站点具有适应计划。
- 100% 资本配置决策考虑 ESG 标准。

这些是公司目标，不代表截至资料时点已经全部完成。网络韧性、能源消耗、站址许可、视觉影响、电磁环境和社区关系也会影响项目交付速度和成本。[S13][S23]

## 十二、主要风险与反证

### 12.1 MNO 合并、RAN sharing 和去站

运营商合并或共享无线接入网络后，重复站点可能被拆除，直接造成 churn。长期合同和去站补偿可以延缓冲击，但不能永久消除需求下降。[S01][S02]

### 12.2 客户集中与续约

2024 CMD 口径中，前三大客户约占收入 48%。大型 MNO 的信用、资本开支、议价和续约条款会直接影响 Cellnex。长期合同的价值取决于续约时的价格和站点数量，而不仅是合同年限。[S01][S03]

### 12.3 通胀错配

客户收入可能有 CPI cap 或固定 1%-2% escalator，而土地、维修、税费和部分供应商成本可能按更高通胀增长。能源 pass-through 只能覆盖能源风险，不能覆盖所有运营成本。[S02][S03]

### 12.4 杠杆、利率和再融资

净债务约 EUR 20.8bn，长期租赁和债务均会影响权益现金流。固定利率比例较高能缓冲利率冲击，但到期再融资、评级、信用利差和现金回报仍需持续跟踪。[S01][S02]

### 12.5 BTS 执行和资本回报

BTS 需要土地、规划、许可、施工、供应链、供电和验收。延期或成本超支会推迟现金回收；单租户新站在早期还会稀释 tenancy ratio。公司的项目级 IRR、合同回报和长期共址假设没有全部公开。[S02]

### 12.6 相邻业务质量不透明

DAS、光纤、Edge、IoT、RANaaS 和 Broadcast 的独立 EBITDAaL、合同期限、资本回报和客户集中度披露有限。不能因为它们都属于“数字基础设施”就假设拥有 Towers 同样的经营杠杆。[S01]

### 12.7 技术替代和网络架构变化

频谱效率、Open RAN、网络共享、卫星直连终端和更高效的主动设备可能改变站址需求。公司认为卫星主要补充而非替代地面容量层，这是公司判断，不是独立行业结论，应持续验证。[S02]
