# 百事利润表与资本回报分析

截至：2026-10-28。PepsiCo, Inc.（NASDAQ: PEP，CIK 77476），合并US GAAP；完整历史FY2016—FY2025，最新实际2026Q3。金额输入为百万美元，正文及图表主要为亿美元；EPS为美元。延续现有研究，原Word与Excel不作写入。

## 判断

百事十年盈利规模扩大，但集团层面的持续利润率扩张并不明显。EPS增长除经营利润外，也得到税率下降及股数减少支持。2025年较高的ROE不能替代经营ROIC；已核验的经营资本回报显示，2023—2024年Core调整后回报改善，2025年又小幅回落。最新报表利润反弹强于Core增长，不能将同比低基数恢复直接外推为长期增长能力。

## 利润表：规模增长尚未转化为持续扩张的利润率

2016—2025年收入从627.99亿美元升至939.25亿美元，CAGR4.57%；Core营业利润从101.65亿美元升至149.12亿美元，CAGR4.35%。Core营业利润率从16.19%变为15.88%。2016—2022年总体承压，2023—2024年恢复，2025年略降。事实支持“盈利规模增长”，并不支持“集团利润率持续抬升”。

毛利率2016年55.06%，2021年53.35%，2022年53.03%，2025年54.15%；SG&A占收入2016年39.45%，2025年39.78%。不能把毛利率变化全归因于原料，因为产品、地区、并购处置和会计调整也影响报表口径。2025年官方MD&A明确列示销量、经营成本、商品成本及关税压力，以及定价、生产率节约与广告费用变化的对冲。

2025年GAAP营业利润114.98亿美元，同比−10.8%；Core营业利润149.12亿美元，同比+1.5%。两者净差34.14亿美元，调节包括减值及其他费用19.46亿美元、重组9.64亿美元、并购处置相关费用4.53亿美元，以及其他正负项目。Core提高跨期可比性，减值所揭示的资本配置后果与重组现金成本仍需保留。不能把Core统一称为纯经济利润或纯现金利润。

## 净利润、税率及EPS

2016—2025年Core归母净利润CAGR5.27%，Core EPS CAGR5.92%；GAAP对应为2.98%和3.61%。2017年税改费用及2018年特殊税项收益显著扰动GAAP净利润，2018年利润与ROE高点不能直接解释为经营能力跃升。

按明确顺序的算术分解，Core EPS从约4.85美元增至8.14美元：营业利润贡献约2.47美元，税率变化约0.48美元，股数变化约0.44美元，养老金、净利息及少数股东合计约−0.10美元。税率与股数约解释累计EPS增量的28%。分解顺序影响各项数值，不代表唯一因果归因；股数使用稀释加权平均股数，不能替代期末实际缩股。

2025年Core营业利润增加2.14亿美元，但Core养老金收益减少1.21亿美元、净利息及其他费用增加2.02亿美元，税费与少数股东带来0.39亿美元对冲，Core归母净利润最终减少0.70亿美元。Core EPS由8.16美元降至8.14美元。营业利润、净利润和EPS的增长机制应分别判断。

2026年前三报告期（36周），收入同比+6.7%，GAAP营业利润+44.8%，Core营业利润+5.1%，Core归母净利润+4.3%，Core EPS+4.6%。Core营业利润率从16.78%降至16.54%，Core有效税率从20.17%升至21.47%。报表反弹受到上年减值等比较基数及当期调节项目影响；Core口径也需结合关税退税、销量、定价及生产率变化判断，不直接等同纯销量增长。

## 资本回报

沿用分析师确认的资产端定义：

```text
经营IC = 总资产 − 投资类资产 − 现金类资产（含可识别受限现金）
平均经营IC = (期初经营IC + 期末经营IC) / 2
NOPAT = GAAP营业利润 − 当期实际集团所得税费用
经营ROIC = NOPAT / 平均经营IC
经营ROIC = (NOPAT / 收入) × (收入 / 平均经营IC)
```

本定义保留商誉、商标、租赁使用权、税务押金及养老金净资产，不扣经营性负债。它是报表分析口径：实际集团税费包含特殊及投资税项，TBG等联营损益亦可能嵌入营业利润；不额外加计权益法收益，也不称为已经完全隔离的直接经营业务经济回报。

| 指标 | FY2022 | FY2023 | FY2024 | FY2025 |
|---|---:|---:|---:|---:|
| 平均经营IC（亿美元） | 832.29 | 844.60 | 864.67 | 900.41 |
| NOPAT（亿美元；同比） | 97.85（+8.5%） | 97.24（−0.6%） | 105.67（+8.7%） | 95.49（−9.6%） |
| NOPAT / 收入 | 11.33% | 10.63% | 11.50% | 10.17% |
| 经营IC周转率 | 1.038× | 1.083× | 1.062× | 1.043× |
| 经营ROIC | 11.76% | 11.51% | 12.22% | 10.61% |
| Core调整后回报参考 | 11.96% | 13.23% | 13.79% | 13.53% |

Core回报参考单独定义为`(Core营业利润 − Core所得税) / 同一平均经营IC`，使用公司调整税费，保留减值后的账面资本；它不替代实际税费经营ROIC，不是纯现金回报。

2025年经营ROIC同比下降约1.62个百分点。先按原平均资本计算NOPAT变化，再计算资本分母变化，分别解释约−1.18和−0.44个百分点。Core参考回报仅下降约0.26个百分点，说明减值等报表项目解释了相当一部分降幅，但资本周转同样从1.062×降至1.043×，尚未显示2025年新增账面资本带来更高周转。2023—2024年Core回报曾改善，不能把四年历史描述为单向恶化。

2025年ROE42.86%，远高于经营ROIC10.61%；这反映资本范围与融资结构的差异，历史分红回购压低账面权益也影响ROE。2018年ROE97.91%又受到特殊税项收益抬高。最新TTM ROE52.28%、ROA10.04%，其中报表利润恢复的影响需与真实资本效率变化分开。未估计资本成本，不作“回报高于WACC”的判断；并购形成的资产和当年部分期间盈利，也不足以测算单笔收购ROIC。

## 缺口、可比性与证据

- FY2016—FY2020其他资产内独立投资余额无法连续识别；FY2021缺少完整FY2020期初经营IC。因此不强算FY2016—FY2021经营ROIC。
- 季报虽披露部分Celsius及其他债券投资，但没有披露完整的其他资产内投资总额；截至2026Q3的匹配季度平均经营IC仍缺输入，故不将某个已披露投资子集充当全部扣除，也不将缺口填零。最新ROA/ROE采用TTM利润与相隔一年的同季资本。
- FY2016 ROA/资产周转缺少与FY2017递延税列报一致的FY2015期初总资产；ROE期初权益不受该重分类影响，可连续计算。
- 金融资产公允价值总表可能已含主表现金、短投及其他投资；按既有逐科目映射去重，不重复扣减证券总额。
- 2016年原始营业利润在后续养老金列报调整后的比较数优先；所有期间沿用现有底稿的最新可比重列。2022年果汁交易收益以原始负费用符号衔接营业利润，不把收益再扣一次。
