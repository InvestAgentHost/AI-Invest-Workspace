# 洛克希德·马丁深度研究代理运行日志

- 日志重建日期：2026-09-01
- 研究截止日期：2026-08-31
- 研究对象：Lockheed Martin Corporation（NYSE: LMT）
- 日志用途：把本次研究中的用户触发、代理关注点、证据处理、执行动作、产物、质量门和遗留问题整理成可训练的代理行为轨迹。
- 时间精度：原始交互未保存每条消息的精确时分，本日志使用用户回合顺序和工作区审计日期，不虚构精确时间。

## 重要说明：过程摘要不是隐藏思维链

本文件不提供模型内部逐字的私有思维链，也不把不可验证的内在推理伪装成事实。这里记录的是可复核的高层决策摘要：

1. 用户提出了什么约束或纠偏。
2. 代理当时需要解决的研究问题是什么。
3. 代理采用了什么证据和执行路径。
4. 形成了什么判断、文件和状态。
5. 哪些问题仍未解决，以及它们如何影响发布门。

这种形式比逐字思维链更适合训练 agent：它能学习状态转移、证据分级、失败恢复、用户反馈吸收和停止条件，而不会学习不可审计的臆测文本。

## 运行状态机

```text
用户目标
  -> 计划与边界
  -> 选择已审核能力
  -> 建立研究上下文与证据台账
  -> 获取原始资料
  -> 规范化十年数据
  -> 先恢复原始报表，再计算衍生指标
  -> 按章节写作
  -> 用户逐章审核与纠偏
  -> 重写/重算
  -> 独立校验与发布审查
  -> PASS / PARTIAL / BLOCKED
```

### 代理在本次运行中使用的状态标签

| 状态 | 含义 |
|---|---|
| `PLAN` | 只定义研究范围、章节和证据路径，尚未进入实际采集 |
| `ACQUIRE` | 获取 SEC、公司、独立资料和管理层纪要 |
| `NORMALIZE` | 把不同年份、重述口径和分部口径整理成可追溯序列 |
| `RECONSTRUCT` | 还原报告原值、建立桥接并检查勾稽 |
| `WRITE` | 依据已验证证据写入章节 |
| `REVIEW` | 接收用户审核，定位结构、数据或结论问题 |
| `REVISE` | 按审核意见重写或重算 |
| `VALIDATE` | 运行格式、算术、来源和包级检查 |
| `PARTIAL` | 有用但仍存在会改变结论的证据缺口，不升级为正式建议 |

## 代理实际采用的证据规则

### 1. 事实和判断必须分层

- `FACT`：SEC、正式公司披露或独立来源明确报告的事实。
- `COMPANY_CLAIM`：管理层或公司材料中的声明，尤其是前瞻性指引。
- `CALCULATION`：由已记录输入计算出的指标、估值或桥接。
- `JUDGMENT`：基于多个事实形成的分析判断。
- `ASSUMPTION`：模型为估值或压力测试设置的参数。
- `UNRESOLVED`：证据不足，不能用推测填补。

### 2. 不能把可见度当价值

backlog 只能先通过 funded、已定价、可交付部分进入收入和现金流，再进入估值；不把 backlog 总额直接加到企业价值。

### 3. 先报告值，再衍生值

财务章节必须先展示报告原值和来源定位，再说明重述、养老金、项目损失、合同资产/负债等桥接，最后计算 ROIC、现金覆盖率或 DCF。

### 4. 异质集团采用路由匹配的估值

四个分部合同类型、生命周期、利润风险和现金转换不同，SOTP 为主；DCF 必须说明是企业 FCF 还是股权 FCF，不能重复扣债务；股东 IRR 必须明确股息/回购 convention。

### 5. 管理层纪要不完整时降低置信度

如果只能取得搜索片段：保存 provider ID 和访问日期，记录完整文件下载失败；只作方向性证据，不能伪造逐字稿、speaker attribution 或独立验证结果。

### 6. 用户纠偏优先改变结构，而不是只改措辞

本次纠偏对应的结构性动作包括：

- “只抓 2016” -> 扩展为 FY2016-FY2025。
- “表格难辨认” -> 分部数据拆入各分部小节。
- “补同比” -> 增加四类 YoY/百分点指标。
- “先还原原始报表” -> 调整第四章的证据顺序。
- “缺 ROIC/资产堆积/现金流向” -> 增加计算和图形产物。
- “第五章重复” -> 改成跨章节驱动综合，不重复指标表。
- “估值最重要” -> 用最新纪要重审现金质量、过渡年和资本配置。
